# Задача: Wrocław — места по сайтам, кусками по 10

**Исполнитель:** Antigravity (ПК) — контейнер выбирает диспетчер; на кусок — не картограф этого куска. Несколько контейнеров могут работать параллельно, каждый — на своих кусках.
**Роль:** Data agent + Content agent.
**Тип:** новый город, куски по 10 мест с воротами, партия (PR) — 1–3 куска.
**Ветка PR:** `city/wroclaw`.
**Зависимости:** `pc-city-wroclaw-maps.md` — каждый кусок берётся, когда кусок карты с тем же номером запушен картографом.
**Срочность:** обычная.

**Сейчас (проверяющий, 2026-10-02, решение владельца):** **обязательная.** Wrocław заканчиваем целиком до общей ревизии. Смержены куски 01–02 (VET_CLINIC 1–20). Дальше по порядку: кусок 03 (VET_CLINIC 21–30, у `agy4` готов, не закоммичен — довести ворота, commit, push, PR в `city/wroclaw`), потом куски 04–10 по мере готовности карты. Когда смержены все куски — проверяющий уводит `city/wroclaw` в `main` одним PR.

Владелец (2026-10-02): полный новый город Wrocław на ПК. Порядок —
`docs/pc-agents/pipeline.md`: каждые 10 мест с карты сразу идут на сайты.

Перед работой — `docs/playbooks/quality.md`, `docs/playbooks/add-city.md`
(разделы 1–3, 5, 7) и `docs/pc-agents/lessons.md`.

## Что сделать в каждом куске

Места куска NN — строки `data/cities/wroclaw/candidates.csv` этого куска
(ветка картографа `pcN/wroclaw-00-maps`). Для каждого места — все поля
`docs/card-spec.md`, языки текстов — `en` и `pl`:

- Столбцы Maps — **копией из `candidates.csv`**, Google Maps не
  открывать (`add-city.md`, «Партии», таблица «Откуда»).
- С сайта и официальных соцсетей: что делают, часы, языки,
  специальности и неотложка (ветклиники), факты, цены — только 6 услуг
  категории (`card-spec.md`, «Цены», дописать в `prices.csv`), логотип
  (`add-city.md` §5).
- Тексты — правила `add-city.md` §3: только то, что есть в данных;
  улица и район — только из адреса и координат.
- Места без сайта и соцсетей — только то, что уже в строке
  `candidates.csv`.

К каждому значению с сайта — строка в `evidence-<NN>-<категория>.csv`:
цитата со страницы как есть, ссылка на эту страницу
(`add-city.md`, раздел 1.4). Цитата — текст страницы, не её заголовок
(урок У-11).

Кусками по 10, после каждого — ворота:
1. собрать 10 (файл куска `businesses-<NN>-<категория>.csv`);
2. `cd website && npm run gate -- wroclaw`;
3. `GATE FAIL` — исправить по списку, заново открыв источник, и снова
   (3-й круг: несошедшееся — пусто и `none (...)`);
4. `GATE PASS` — закоммитить кусок вместе со штампом `checks/…json`;
5. следующие 10.

Ветка куска — `pcN/wroclaw-<NN>-<категория>` от ветки картографа (пока
карта не смёржена в `city/wroclaw`), PR — в `city/wroclaw`. Перед
облачным ревью — «Проверка напарника» (`pipeline.md`).

## Партии

Пилот (кусок 01) ждёт ревью; дальше — по куску на PR (или до 3 подряд
одного контейнера), не дожидаясь проверки, не больше 3 PR на проверке у
контейнера. Номера кусков — как у карты.

| # | Что | Ветка |
|---|---|---|
| 1 | VET_CLINIC 1–10 — кусок 01 (пилот) | `pcN/wroclaw-01-vet` |
| … | следующие куски — по мере готовности карты, номер = номер куска карты | `pcN/wroclaw-<NN>-<категория>` |

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается,
`check-city` пропускает. Если так у трети мест партии и больше — не
собирать дальше: открыть PR с тем, что есть, и описать проблему в
разделе `## Открытый вопрос`. Сдать меньше мест с объяснением —
нормально; возврат PR бывает за выдумку, не за честный пробел.

## Чего не делать

- Не выдумывать и не «оценивать» (`quality.md`, правила 1, 7).
- Один абзац на всю категорию — возврат (описания Кошице и Варшавы).
- Не менять столбцы Maps и чужие куски: правка после ворот снимает PASS.
- Не трогать код сайта, скрипты, другие города.

## Готово, когда (для каждой партии)

- PR открыт в `city/wroclaw`, заголовок `Wrocław — кусок <NN> <категория>`.
- У каждого куска — `GATE PASS` (штамп в `checks/`).
- `cd website && npm run check-city -- wroclaw` → `READY` (с таблицей
  «Gates») и `npm run verify-city -- wroclaw` → `VERIFIED`, вывод обоих
  целиком в PR.
- Комментарий `## Проверка напарника (ПК N)` с `OK`.
- Самопроверка `quality.md` (§2) в PR, блок ИТОГ в конце работы.

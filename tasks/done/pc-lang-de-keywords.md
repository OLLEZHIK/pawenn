Перед работой — `docs/playbooks/quality.md`, `docs/seo/keywords/README.md` (методика целиком) и образец — `docs/seo/keywords/cs.md` (то же самое для чешского).

## Что сделать

Файл `docs/seo/keywords/de.md` в формате `cs.md`:

1. **Страна — Austria (`geo=AT`)**, Trends за 12 месяцев; подсказки — `google.at`, язык `de`. Базовый город — Wien. Австрийский немецкий («Tierarzt», «Hundesalon», «Hundeschule»), но варианты из Германии, которые австрийцы тоже ищут («Hundefriseur», «Hundepension»), включить в сравнение.
2. **Категории** (по группам сравнения до 5 вариантов, ссылка Trends над каждой группой): ветеринар; груминг (Hundesalon / Hundefriseur / Hundepflege …); отель (Hundepension / Tierhotel / Katzenpension / Tierpension …); дрессировка (Hundeschule / Hundetraining / Hundetrainer …); зоомагазин (Zoofachgeschäft / Tierhandlung / Zoohandlung / Futterhaus-подобные бренды не считать); передержка и выгул (Hundebetreuung / Hundesitter / Gassi-Service / Tiersitter …).
3. **Услуги из цен** (`docs/card-spec.md`, «Цены»): как называют услугу, по которой ищут цену.
4. **Признаки ветклиник:** круглосуточно / Notdienst / Samstag / Sonntag / Exoten / Hausbesuch / Englisch — как формулируют запрос.
5. Решение по каждой группе — «главный» (наибольшая цифра, правило из README) / «второй» / «нет»; **слаг страницы — главный запрос, латиницей, без умляутов или с `ae/oe/ue`** (записать, какой вариант выбран и почему; слаги после запуска не меняются).
6. Колонка Planner — `—` во всех строках (аккаунта Planner нет), как в `cs.md`.

Каждая цифра — со ссылкой Trends и датой; нет данных — `н/д` (инструмент открыт, цифры не дал) или `—` (инструмент недоступен), причина в начале файла. Не оценка (`quality.md`, правила 1 и 7).

## Если инструмент не работает

Не открылся Trends или подсказки — поле `—`, причина в начале файла. Если так у трети групп — не доделывать файл; открыть PR с тем, что есть, и описать проблему в `## Открытый вопрос`.

## Чего не делать

- Не выдумывать цифры; не пересчитывать индексы между группами Trends.
- Не трогать код сайта и словарь `de.ts`.

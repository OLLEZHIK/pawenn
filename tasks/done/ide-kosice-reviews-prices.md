# Задача: Кошице — сводки отзывов и проверка цен

**Исполнитель:** Antigravity IDE — **закрыта 2026-09-27**: 4 сводки приняты
(PR #156 → #151), остаток передан Antigravity:
`tasks/antigravity-kosice-reviews-maps.md`.
**Роль:** Content / data agent.
**Тип:** контент по отзывам + добор данных, объём средний.
**Ветка:** `antigravity/kosice-reviews-prices`
**Зависимости:** нет (Кошице смёржен в PR #144, дубль Strapačik убран в PR #151 — перед
началом `git pull` свежего `main`; если #151 ещё не смёржен — начать от его ветки
`claude/kosice-followups`).

Решение владельца (2026-09-27): довести Кошице до уровня Братиславы.
Перед работой — `docs/playbooks/quality.md`.

## Часть 1. Сводки «Что говорят клиенты» (главное)

Всё — по `docs/playbooks/review-insights.md` (формат, правила,
проверка). Вход в Google не обязателен: Братиславу (PR #121) делали
без него. Сначала открыть карточку места без входа, сортировка «Новые»:
видны отзывы с текстом за полгода — работать так. Не видны (Google
показывает урезанную карточку: лента обрывается на 4–5 отзывах в окне, а
оценок сотни — так было в PR #156) — только тогда войти; нельзя войти —
место в список «без сводки» с причиной, текст не писать.

- Места Кошице с **≥ 20 оценками** Google — сейчас **53** (ветклиники 23,
  зоомагазины 13, груминг 10, дрессировка 3, гостиницы 2, передержка 2).
- Файл на место: `data/cities/kosice/review-insights/<slug>.json`; языки
  сводки — `en` и `sk`.
- Место, для которого сводку сделать нельзя (меньше 5 отзывов с текстом,
  отзывы не открываются), — не пропускать молча: список с причиной в PR.

## Часть 2. Цены — проверить «not published»

У 50 мест (не зоомагазинов) в `notes` стоит `prices: not published` без
указания, где смотрели. В Братиславе цены есть у 45 мест из 96, в Кошице —
у 10 из 77.

Для каждого из 50 мест:
- нашёл опубликованный прайс (сайт, страница «cenník», Facebook/Instagram
  места) — добавить строки в `data/cities/kosice/prices.csv` по
  `docs/card-spec.md`, «Цены» (коды своей категории, `source_url`,
  фиксированная цена — в оба поля, «od X» — только `price_from`);
- не нашёл — заменить заметку на `prices: none (<где смотрел>)`, например
  `prices: none (site - no cenník page, fb - not posted)`.

## Чего не делать

- Не выдумывать и не «оценивать» цены и отзывы (quality.md, правила 1, 7).
- Не цитировать отзывы и не называть авторов — только обобщение.
- Не трогать остальные поля мест, код сайта, другие города.
- Не переписывать историю ветки после ревью.

  части 2 — сколько мест получили цены, сколько `prices: none (...)`.
- Самопроверка `quality.md` (§2) в PR.

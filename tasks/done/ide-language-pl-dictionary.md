# Задача: польский язык, шаг 2 — перевод интерфейса

**Исполнитель:** Antigravity IDE
**Роль:** Content agent.
**Тип:** перевод, объём средний.
**Ветка:** `antigravity/dictionary-pl`
**Зависимости:** `tasks/ide-language-pl-keywords.md` (названия категорий,
услуг и признаков берутся из карты ключевых слов).

`docs/playbooks/add-language.md` §1, шаг 2. Подключение к сайту (шаг 3)
делает сессия Claude — по этому PR.

## Что сделать

1. **`website/lib/dictionaries/pl.ts`** — копия `en.ts`, все строки на
   польском. Живой язык, не калька; строки-функции переводить целиком,
   с правильными формами: для чисел `plural("pl", n, { one, few, many,
   other })` (в польском 1 / 2–4 / 5+ разные: «1 miejsce, 2 miejsca,
   5 miejsc»). «W mieście» не писать — оно из `in_city` города.
   Файл пока не подключён: ошибки typecheck **только** из-за того, что
   `"pl"` ещё не в `LOCALES`, — ожидаемы; других быть не должно.
2. **`docs/i18n/pl-labels.md`** — таблица польских подписей для всего,
   что не в словаре (по одной строке на код, колонки «код / EN / PL»):
   - категории: `LABELS`, `SINGULAR`, `PLURAL`, `SEO_TITLE`, `BLURBS`
     из `website/lib/categories.ts`;
   - услуги цен — `website/lib/services.ts` (и строки «что входит»);
   - специальности ветклиник — `website/lib/vet.ts`;
   - факты «Dobré vedieť» — `website/lib/facts.ts` (подписи и вопросы-
     ответы `FAQ`);
   - название языка в переключателе: `Polski`.
   Названия — словами из `docs/seo/keywords/pl.md` («главный» вариант).

Юридические страницы и Help не переводить (только английский).

## Готово, когда

- **PR открыт**; в нём самопроверка `quality.md` (§2).
- Все ключи `en.ts` есть в `pl.ts` (кроме типов ошибок нет).
- Таблица `docs/i18n/pl-labels.md` покрывает все коды из перечисленных
  файлов.
- PR не мёржится отдельно — его подключает сессия Claude вместе с кодом.

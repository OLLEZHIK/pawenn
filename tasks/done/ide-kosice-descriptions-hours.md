# Задача: Кошице — описания и часы работы по сайтам мест

**Исполнитель:** Antigravity IDE
**Роль:** Data / content agent.
**Тип:** исправление данных города, объём средний (77 мест).
**Ветка:** `antigravity/kosice-descriptions-hours`
**Зависимости:** нет. Начать от ветки `claude/check-city-templates` (в ней
новые проверки `check-city`; отдельно не мёржится, чтобы не тратить сборку
Vercel, — уйдёт в `main` вместе с этим PR).

Поставлено «левой рукой» по указанию владельца (2026-09-28). Сводки
отзывов в эту задачу **не входят**: их делает «левая рука» через API
отзывов Google, прежняя задача `antigravity-kosice-reviews-maps.md`
закрыта.

## Что не так сейчас

`cd website && npm run check-city -- kosice` печатает `NOT READY`:

1. **Описания — шаблоны.** У 75 из 77 мест все четыре текста
   (`short_description`, `short_description_local`, `description`,
   `description_local`) — один абзац на категорию: 27 ветклиник
   («Veterinary practice providing preventative and clinical
   healthcare…»), 17 зоомагазинов, 15 грумингов, 9 кинологов, 4 отеля,
   3 пет-ситтера. Там есть выдуманное («Helpful staff advises on proper
   animal nutrition», «Patients are treated with care»).
2. **Часы — только выходные.** У 35 мест `opening_hours` — одна строка
   вида `sa closed; su closed` или `su closed`: когда место открыто, не
   сказано. Пример: `veteras-veterinar-kosice-a-okolie`,
   `lu-ma-kupelna-pre-psy`, `abc-zoo`, `m-vet`. Полный список —
   в выводе `check-city` (строка `opening_hours`, 42/77).
3. **Petstar и Vetanimal — возможно, одно место.** `petstar-mvdr-jozef-berescak`
   (Národná trieda 56, 602 оценки) и `veterinarna-klinika-vetanimal`
   (Slovenská 93, 55 оценок) — 100 м друг от друга, одинаковые часы и
   описания; по наблюдению «левой руки», карточка Petstar в Google Maps
   показывает адрес и телефон Vetanimal.

## Что сделать

Перед работой — `docs/playbooks/quality.md` и `docs/playbooks/add-city.md`,
раздел 3 «Тексты: правила» (там новое правило про шаблоны).

1. **Описания — все 77 мест.** Открыть сайт места (или официальную
   соцсеть, если сайта нет) и написать четыре текста **про это место**:
   что делают, для кого, чем отличаются (специальности, услуги,
   животные, неотложка, выезд). `_local` — живой словацкий, не перевод.
   Нет ни сайта, ни соцсети — короткий текст только из того, что есть
   в карточке Google Maps и уже в данных (категория, `specialties`,
   `facts`), без деталей, которых нигде нет. Тексты UVLF и
   `cezi-vet`-подобных мест, которые уже уникальны, — проверить и
   оставить, если верны.
2. **Часы — 35 мест.** Часы с сайта места; нет на сайте — копия с
   карточки Google Maps (в `hours_source_url` — откуда). Все дни, что
   указаны. Нет нигде — `opening_hours` пустое и в `notes`
   `hours: none (site - not stated, maps - not stated)`.
3. **Petstar / Vetanimal.** Открыть обе карточки Google Maps и оба
   сайта/страницы. Если это одно место (один адрес, один телефон,
   Petstar переехал или переименован) — оставить одну запись по
   правилу дублей `add-city.md`, вторую убрать (или `closed=yes`, если
   Google пишет «Закрыто навсегда»). Если два разных места — у каждого
   свои адрес, телефон и часы с его карточки. Что увидел — в PR.

В `businesses.csv` менять **только** эти столбцы: четыре текста,
`opening_hours`, `hours_source_url`, `hours_observed_at`, `notes`, и
для пункта 3 — поля двух мест. Сохранять файл в той же кодировке и с
теми же переводами строк.

## Чего не делать

- Не писать один текст на несколько мест и не менять в нём только
  название — `check-city` это ловит.
- Не выдумывать (quality.md, правила 1, 7): «опытный персонал»,
  «индивидуальный подход», «качественная косметика» — только если это
  прямо написано на сайте места, и своими словами.
- Не копировать тексты с сайтов дословно.
- Не трогать цены, факты, рейтинги, сводки отзывов, код сайта, другие
  города.

## Что сделать в каждой партии

Для каждого места: карточка Google Maps (ссылка — `google_maps_url` в
данных), сортировка «Najnowsze», отзывы с текстом за последние
6 месяцев; меньше 5 — за 12, потом за 24 месяца (плейбук, «Для каких
мест»).

- **Кусками с воротами** (`quality.md`, правило 10): сводки одного куска
  → `cd website && npm run gate -- warszawa` → `GATE FAIL` — исправить по
  ленте и снова, `GATE PASS` — закоммитить вместе со штампом
  `data/cities/warszawa/checks/insights-<NN>.json` → следующий кусок.
- ≥ 5 отзывов — файл `data/cities/warszawa/review-insights/<slug>.json`
  по плейбуку за самый короткий подходящий период, языки **`en` и
  `pl`** (польский — живой, не перевод). В файле — **лента `feed`**:
  каждый отзыв с текстом за период, сверху новые — `ago` как пишет
  Google, `months`, `stars`, `topics`. Карточки — из ленты: три самые
  частые темы, `mentions` и `sentiment` — как их считает плейбук.
- И за 24 месяца < 5 — файл не делать, место — в таблицу PR «без
  сводки» с реальным числом (сайт покажет короткий блок сам).

## Если инструмент не работает

Лента не открывается или обрывается (урезанная карточка без входа:
4–5 отзывов при сотнях оценок, `review-insights.md`) — сводку не писать,
место — в таблицу «без сводки» с причиной. Это засчитывается. Если так у
трети мест партии и больше — не продолжать: открыть PR с тем, что есть,
и описать проблему в разделе `## Открытый вопрос`. Сдать меньше мест с
объяснением — нормально; возврат PR бывает за выдумку, не за честный
пробел.

## Чего не делать

- Не выдумывать и не «оценивать» (quality.md, правила 1, 7): лента —
  то, что показал Google, не «примерно».
- Не цитировать отзывы и не называть авторов — ни в текстах, ни в
  ленте (в ленте только дата, звёзды, темы).
- Не добивать тексты общими фразами до нужной длины.
- Не брать файлы из ветки `antigravity/warszawa-reviews` — это
  непринятая версия.
- Не трогать `businesses.csv`, цены, код сайта, другие города.

## Готово, когда (для каждой партии)

- **PR открыт в `main`** (коммит — не сдача), заголовок
  `Warszawa: review summaries — партия <N>`.
- У каждого куска партии — `GATE PASS` (штамп в `checks/`).
- `cd website && npm run check-city -- warszawa` → в разделах
  `review-insights format` и «Chunks without a valid gate» нет строк про
  места этой партии; вывод в PR.
  (Остальные строки `NOT READY` Варшавы — логотипы, описания — не
  этой задачи: перечислить их в PR как «не моё».)
- В PR — таблица по местам партии: ссылка на Maps, отзывов с текстом
  за взятый период, период, темы карточек с `sentiment`, сводка есть /
  нет и почему.
- Самопроверка `quality.md` (§2) в PR.

## Ревью ветки `antigravity/warszawa-reviews` (коммит 440f614) — не принято

«Левая рука» по указанию владельца, 2026-09-28. 63 файла, формат
правильный, тексты не повторяются. Но **числа и содержание не похожи на
прочитанную ленту отзывов**:

1. **Числа невозможные.** `petsy-domowy-hotel-dla-psow-i-kotow-warszawa`:
   89 отзывов с текстом за полгода при 120 оценках за всю жизнь места;
   `psybrothers-salon-groomerski`: 41 из 77. `check-city` (ветка
   `claude/check-city-templates`) теперь это ловит: число за период
   больше половины всех оценок — ошибка.
2. **Сводка расходится с видимыми отзывами.**
   `calodobowa-klinika-weterynaryjna-marysin`: из трёх свежих отзывов,
   что Google показывает первыми, два критических — 1300 zł за анализ
   крови ночью и неудачный забор крови у старой собаки. В сводке: персонал
   — «positive, 50», результаты — «positive, 29» («спасают после ДТП,
   отравлений, заворота желудка»), цены — «mixed». Критики лечения нет
   ни в одной карточке.
3. **Одинаковая форма у всех 63:** ровно по 85 строк, у 43 все три
   карточки «positive», период у всех один. Прочитать ленты по 100–170
   отзывов у 63 мест за час вручную нельзя.

**Что делать** (теперь — партиями выше, доказательство — лента `feed` в файле). Не править точечно — переделать по ленте каждого места.
Для каждой сводки в PR — **доказательство чтения**: даты всех отзывов с
текстом за период (список) и для каждой карточки 2–3 даты отзывов, на
которых она основана. Карточка с критикой — если критика есть в ленте
(`mixed`/`negative`). Периоды — ступенями 6 → 12 → 24 месяца (плейбук,
новая редакция). До PR: `check-city -- warszawa` с проверками из
`claude/check-city-templates` — без ошибок.

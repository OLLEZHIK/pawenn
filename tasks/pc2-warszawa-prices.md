## Что сделать

Для каждого места с `prices: none (...)` и сайтом — открыть сайт и
искать прайс: меню «Cennik», «Ceny», «Usługi», страницы услуг, PDF.
- Нашёл цену услуги из списка категории — строка в
  `data/cities/warszawa/prices.csv` (все колонки стандарта, `currency`
  пусто или `PLN`, `source_url` — страница прайса, `observed_at` —
  дата) и цитата строки прайса в
  `data/cities/warszawa/evidence-prices.csv`: поле `price:<код>`,
  цитата с суммой как на странице (`add-city.md`, раздел 1.4;
  `check-city` проверяет, что сумма есть в цитате).
- Заметку `prices: none (...)` у такого места убрать из `notes`.
- Прайса нет — заметку оставить, но написать, где смотрел:
  `prices: none (site - cennik: price on request, checked 2026-09-29)`.

**Кусками по 10 мест:** 10 мест → `npm run check-city -- warszawa
--only=<10 slug>` (раздел «prices» и «evidence» без строк этих мест) и
`npm run verify-city -- warszawa --only=<10 slug>` (цитаты найдены,
«Price page on the site, but notes say none» — пусто) → коммит →
следующие 10.

**Конвейер** (`AGENTS.md`, шаг 3): первые 10 мест — пилот, PR и ждать
ревью; дальше по 20–30 мест в PR, не дожидаясь проверки. Ветка — от
`pc2/warszawa-descriptions`, пока тот PR не смёржен (оба меняют
`businesses.csv`), иначе от свежего `main`.

## Если инструмент не работает

Сайт не открылся — `prices: none (site did not open, <дата>)`. Это
засчитывается. Если так у трети мест куска и больше — остановиться и
спросить в PR (`## Открытый вопрос`).

## Чего не делать

- Цены «по телефону», из каталогов, отзывов, Booksy без страницы места —
  не брать.
- Не переводить в евро, не округлять, не складывать то, что стандарт
  не велит складывать.
- Не трогать тексты, логотипы и другие столбцы.

## Готово, когда (для каждого PR)

- PR открыт в `main`, заголовок `Warszawa: prices — <места>`.
- `check-city -- warszawa --only=<места PR>` без строк «prices» и
  «evidence» по этим местам; `verify-city -- warszawa --only=<места PR>`
  → `VERIFIED`. Выводы целиком в PR.
- В PR — таблица: место → найдено цен / `none` и где смотрел.
- Самопроверка `quality.md` (§2) в PR.

# Задача: полнота — каких мест у нас нет (по официальным спискам)

**Исполнитель:** Antigravity (ПК) — контейнер выбирает диспетчер (`AGENTS.md`, владелец 2026-10-02); ветки `pcN/…`, где N — его номер.
**Роль:** Data agent (исследование).
**Тип:** исследование + список кандидатов, куски по 10, партии по 1–3 куска.
**Ветка PR:** `main`.
**Зависимости:** нет.

**Сейчас (проверяющий, 2026-10-02):** свободна: диспетчер даёт свободному контейнеру ПК. Партия 1 — пилот, PR и ждать ревью.

Зачем: каталог ценен полнотой. Сейчас места находят по Google Maps;
у ветеринаров и части других услуг есть официальные списки (например,
регистр Komora veterinárnych lekárov SR). Сверка с ними показывает, кого
мы пропустили. Найденные места дальше проходит CLI по Google Maps — эта
задача Maps не открывает.

Перед работой — `docs/playbooks/quality.md` (правила 1, 7–9),
`docs/playbooks/add-city.md` (раздел про дубли).

## Партии

| # | Что | Ветка |

| 2 | Bratislava VET_CLINIC — остальные; Košice VET_CLINIC | `pcN/registers-02-vet` |

## Что сделать

1. Найти официальный список (регистр палаты, госорган, открытые данные
   города). В PR — какой источник, кто ведёт, дата обновления, есть ли
   адреса. Не нашёл официального — так и написать и остановиться
   (раздел `## Открытый вопрос`); коммерческие каталоги (firmy.sk,
   zoznam.sk) — только как вторичный источник, с пометкой.
2. Сравнить с `data/cities/<город>/businesses.csv` (по названию, адресу,
   телефону; врач и его клиника — одно место, `add-city.md` про дубли).
3. Каждый пропуск — строка в `data/cities/<город>/missing-candidates.csv`:
   ```
   category,name,address,phone,website,source,source_url,quote,observed_at,notes
   ```
   `quote` — строка из реестра как есть. Сомнение, то же ли это место,
   что у нас уже есть, — в `notes` (`maybe_duplicate_of: <slug>`), не
   решать самому.
4. Кусками по 10 строк, после куска — перечитать каждую строку по
   источнику, коммит.

## Если инструмент не работает

Не открылся сайт, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается.
Если так у трети строк партии и больше — не собирать дальше: открыть PR
с тем, что есть, и описать проблему в разделе `## Открытый вопрос`.
Сдать меньше строк с объяснением — нормально; возврат PR бывает за
выдумку, не за честный пробел.

## Чего не делать

- Google Maps не открывать; места в `businesses.csv` не добавлять —
  только `missing-candidates.csv`.
- Не дописывать телефоны, сайты и адреса, которых нет в источнике.
- Не трогать код сайта, скрипты проверки и `businesses.csv`.

## Готово, когда (для каждой партии)

- PR в `main`, заголовок `Completeness: <город> <категория> — партия <N>`.
- У каждой строки — `source_url` и дословная `quote`.
- В PR: сколько мест в источнике по городу, сколько у нас, сколько
  пропусков, сколько «может быть дубль».
- **Только в пилоте:** `## Отчёт о возможностях`.

**Исполнитель:** Antigravity (ПК) — контейнеры и порядок выбирает диспетчер. Карта — контейнеры с входом в Google (`docs/pc-agents/browser-setup.md`); сайты — любой.
**Роль:** Data agent + Content agent.
**Тип:** новый город (и новая страна), куски по 10, партии по 1–3 куска.
**Ветка PR:** `city/praha` (создаёт картограф от свежего `main`, `add-city.md`, «Партии»).
**Зависимости:** нет. Чешский язык на сайт ещё не подключён: код не трогаем, город собирается в ветке `city/praha` и уйдёт в `main` только после языка (см. «Язык» ниже).
**Срочность:** на ночь, 2026-10-04 → 2026-10-05.

**Сейчас (левая рука, 2026-10-04, слово владельца «дай задачи на ночь»):** диспетчер сначала запускает карту (партия 0) и карту ключевых слов `cs` (партия K) параллельно на разных контейнерах; куски карты по мере готовности отдаёт на сайты (`pipeline.md`).

## Язык

Praha — первый город на чешском (`cs`). Языка в коде нет, поэтому:

- `city.json`: `country` `CZ`, `locale` `cs`, `locales` `["cs"]`, `timezone`
  `Europe/Prague`, `currency` `CZK`, `in_city` `en` «in Prague», `cs` «v Praze».
- Тексты в данных — на `en` и `cs` (колонки `*_local` = чешский), по
  правилам `add-city.md` §3.
- **В `main` город не вливать**, пока диспетчер/владелец не подключит
  язык (`add-language.md`, шаги 2–3): иначе сборка сайта упадёт. Ветка
  `city/praha` живёт отдельно; отчёт `ready-city` по ней можно гонять
  в любой момент.
- Запросы для карты — чешские (список ниже), потому что карты ключевых
  слов `cs` ещё нет (её делает партия K).

## Партия 0: карта

Формат и правила — `add-city.md`, «Партия 0», `candidates.csv` (все
колонки копией с карточки Maps, `observed_at` — дата).

1. Запросы (по каждой категории все, дедуп по карточке):
   - VET_CLINIC: «veterinář Praha», «veterinární klinika Praha»,
     «nonstop veterinář Praha»;
   - GROOMING: «psí salon Praha», «stříhání psů Praha», «kočičí salon Praha»;
   - PET_HOTEL: «psí hotel Praha», «ubytování pro psy Praha»;
   - DOG_TRAINING: «psí škola Praha», «výcvik psů Praha», «kynolog Praha»;
   - PET_SITTING: «hlídání psů Praha», «pet sitting Praha»;
   - PET_SHOP: «zverimex Praha», «krmivo pro psy Praha».
2. **Отбор — «Отбор в большом городе» (`add-city.md`):** в
   `candidates.csv` собрать с запасом (около 200 кандидатов), в город
   берутся 100 лучших: сначала самые популярные, при равенстве —
   с сайтом, логотипом, ценами, часами. Безвестные места без сайта и
   логотипа не брать. Квоты: `PET_SHOP` ≤ 10, `VET_CLINIC` ≤ 50, остальные
   категории — по популярности (грумеры, отели, дрессировка, догситтинг).
   В PR — сколько было кандидатов и какое правило отбора применено.
3. Порядок кусков: VET_CLINIC → GROOMING → PET_HOTEL → DOG_TRAINING →
   PET_SITTING → PET_SHOP; внутри категории — по числу оценок, по
   убыванию; сети — каждый филиал отдельной строкой, но не заполнять
   сетью всю категорию. Закрытые места не включать.
4. Кусками по 10: собрал → коммит, push, в блоке ИТОГ «кусок NN карты
   готов» (диспетчер сразу отдаёт его на сайты).
5. **Сверка вслепую:** другой контейнер (не картограф) собирает 5 из
   10 мест каждого куска и запускает `cd website && npx tsx
   scripts/maps-exam.ts praha ../data/cities/praha/maps-check-<NN>-pcM.csv`
   (`pipeline.md`). FAIL — кусок заново.

## Партии 1…10: места по сайтам

Для каждого места — все поля `docs/card-spec.md`; языки текстов `en` и
`cs`. Столбцы Maps — **копией из `candidates.csv`**, Google Maps не
открывать. С сайта и официальных соцсетей: что делают, часы, языки,
специальности и неотложка (ветклиники), факты, цены (6 услуг категории,
в CZK, дописать в `prices.csv`), логотип (`add-city.md` §5). К каждому
значению с сайта — цитата в `evidence-<NN>-<категория>.csv`
(цитата — текст страницы, не заголовок, урок У-11). Места без сайта и
соцсетей — только то, что в строке `candidates.csv`.

Кусками по 10, после каждого:
1. `cd website && npm run gate -- praha`;
2. `GATE FAIL` — исправить по списку, заново открыв источник (3-й круг:
   несошедшееся — пусто и `none (...)`);
3. `GATE PASS` — коммит куска вместе со штампом `checks/…json`;
4. следующие 10.

Ветка куска — от ветки картографа (пока карта не смёржена в
`city/praha`), PR — в `city/praha`.

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается,
`check-city` пропускает. Если так у трети мест партии и больше — не
собирать дальше: открыть PR с тем, что есть, и описать проблему в
разделе `## Открытый вопрос`. Сдать меньше мест с объяснением —
нормально; возврат PR бывает за выдумку, не за честный пробел.

## Чего не делать

- Не выдумывать и не «оценивать» (`quality.md`, правила 1, 7): нет данных —
  `—` и причина.
- Не добивать до 100 сомнительными местами: 80 честных лучше 100 с догадками.
- Не открывать Google Maps контейнерам без входа и без сданного
  экзамена; в партиях 1…10 Maps не открывать вовсе.
- Не трогать код сайта, чужие города и `main` (кроме PR карты `cs`, партия K).
- Улицу и район в текстах — только из адреса и координат.

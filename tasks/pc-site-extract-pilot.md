# Задача: пилот `site-extract` — кусок сайтов Берлина

**Исполнитель:** Antigravity (ПК) — контейнер выбирает диспетчер (`AGENTS.md`, владелец 2026-10-02); ветки `pcN/…`.
**Роль:** Data agent.
**Тип:** пилот нового метода: один кусок сайтов с `site-extract` вместо ручного обхода каждого сайта (`docs/playbooks/add-city.md`, «Шаг 0 каждого куска»).
**Ветка PR:** `city/berlin` (ветка агента — `pcN/site-extract-berlin-pilot`).
**Зависимости:** `website/scripts/site-extract.ts` в `main` (смёржен, PR #521); в `city/berlin` влит свежий `main` (диспетчер).
**Срочность:** обычная; идёт вместо очередного куска сайтов Берлина, а не сверх него.

**Сейчас:** ждёт диспетчера: выдать свободному контейнеру; кусок — первый ещё не собранный кусок сайтов Берлина по очереди диспетчера (не более 10 мест).

**Зачем (владелец, 2026-10-06):** окна Antigravity — главное ограничение скорости городов. Скрипт `site-extract` делает механическую часть чтения сайтов без модели (на Вене: 85 из 100 сайтов прочитаны за 111 с, 73 телефона из 80 подтверждены на сайтах). Проверяем, ушло ли на кусок заметно меньше времени и запросов, и не стало ли хуже качество.

**Что сделать:**
1. `git fetch origin && git merge origin/main` в ветке (без rebase/force); `cd website && npm install`.
2. Взять 10 мест куска из `candidates.csv`, запустить `npm run site-extract -- berlin --only=<слаги>`; открыть `site-raw/_summary.json`: места со статусом не `ok` читать вручную, как раньше.
3. Собрать кусок по `add-city.md` (описания и переводы — свои; факты, языки, часы, цены — из строк скрипта; цитату в `evidence*.csv` — только после прочтения строки). `phone_check: not-found` — открыть сайт и проверить.
4. `npm run gate -- berlin` до `GATE PASS`, коммит куска со штампом, один PR в `city/berlin`.
5. В блоке ИТОГ — **метрики пилота**: сколько мест из 10 скрипт прочитал сам (`ok`), сколько пришлось открывать руками и почему; сколько минут и запросов (если видно) ушло на кусок против прошлых кусков; что скрипт нашёл неверно или пропустил (например, ложные строки про языки).

**Готово, когда:** PR с одним куском, `GATE PASS`, `check-city` без новых FAIL, `verify-city` VERIFIED, блок ИТОГ с метриками. Принимает пилот диспетчер (`docs/pc-agents/board.md`, «Приёмка пилотов»); без «Пилот принят» метод на другие города не распространяется.

**Если скрипт не работает** (ошибка запуска, пустые файлы у трети мест) — остановиться и написать в PR, не чинить скрипт самому (`website/scripts/` — вне задачи).

# Тест связи: облако → CLI (ПК) → Antigravity (ПК 1)

**Исполнитель:** Antigravity (ПК 1) — контейнер `agy1` на Windows-ПК владельца.
**Ветка:** `pc1/test-ping`
**Сейчас:** выполнить один раз. Это тест цепочки агентов, не рабочая задача.

Задачу передаёт Claude Code CLI на ПК (диспетчер) по указанию владельца.

## Что сделать

1. В свежем `main` создать ветку `pc1/test-ping`.
2. Создать файл `docs/pc-agents/ping.md` ровно с таким содержимым
   (подставить значения):
   ```
   # Ping
   - agent: <содержимое .git/agent>
   - time_utc: <вывод `date -u +%Y-%m-%dT%H:%M:%SZ`>
   - main_head: <вывод `git rev-parse --short origin/main`>
   ```
3. Закоммитить: `Test ping from Antigravity (ПК 1)`.
4. Запушить ветку и открыть **черновой (draft)** PR в `main` с
   заголовком `[тест] ping от Antigravity (ПК 1)`.
5. Последним сообщением — ссылка на PR.

## Нельзя

- Трогать любые другие файлы.
- Мержить PR.
- Брать другие задачи из `tasks/`.

## Готово, когда

Открыт draft PR с одним новым файлом `docs/pc-agents/ping.md`.

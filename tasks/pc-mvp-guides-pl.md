## Что сделать

По `guides.md`: файл, поля front matter, источники, хотя бы один блок каталога и ссылки на соседние статьи. В PR — таблица «утверждение → цитата → ссылка». Перед PR `cd website && npm run check-guides` → `READY`.

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается,
`check-city` пропускает. Если так у трети мест партии и больше — не
собирать дальше: открыть PR с тем, что есть, и описать проблему в
разделе `## Открытый вопрос`. Сдать меньше мест с объяснением —
нормально; возврат PR бывает за выдумку, не за честный пробел.


## Чего не делать

- Не писать медицинские советы, дозировки, лечение (`guides.md`, правило 4).
- Не переносить правила Словакии в польские статьи; не писать «обязательно», пока источник так не говорит.
- Не трогать код сайта: раздел языка появится сам, когда в нём есть статья.
- Не менять существующие статьи `sk`.

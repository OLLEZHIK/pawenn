**Исполнитель:** Antigravity (Mac 2)
**Роль:** Data agent.
**Тип:** исправление данных города, объём маленький (10 мест + добор до 80 %).
**Ветка:** `mac2/kosice-logos`
**Зависимости:** нет. Начать от свежего `main`. Брать **до**
`pc2-warszawa-descriptions.md`. Передано от Antigravity IDE 2026-09-29: сейчас
работают только агенты на Mac (владелец).

**Сейчас (проверяющий, 2026-09-29 13:50):** PR #212 — исправить логотип `veterinarna-klinika-slon` по «Ревью PR #212» (в конце файла) в той же ветке.

Решение владельца (2026-09-28): карточка — главный контент сайта, а
размытая иконка вместо логотипа выглядит хуже, чем инициалы. Теперь
`check-city` проверяет размер логотипа (не меньше 128 px по длинной
стороне и 64 px по короткой), а сайт мелкий файл не показывает. В
Кошице 10 мест с иконкой сайта 15–72 px, нормальный логотип — у 52 мест
из 76 (68 %, нужно 80 %).

Перед работой — `docs/playbooks/quality.md` и `docs/playbooks/add-city.md`,
раздел 5 «Логотипы» (порядок поиска и проверка на белом фоне).

## Что сделать

1. `cd website && npm run check-city -- kosice` — список «Logos too
   small» (10 мест). Для каждого найти настоящий логотип по порядку из
   раздела 5: шапка сайта → иконки сайта от 128 px → Facebook →
   Instagram → бренд сети.
2. Места без логотипа вообще (строки `logo: none (...)` в `notes`) —
   пройти ещё раз по тому же порядку: цель — не меньше 80 % мест с
   логотипом.
3. Не нашли — удалить мелкий файл, `logo_file` пусто, в `notes` —
   `logo: none (где смотрели)`.

Файлы — `website/public/logos/kosice/<slug>.png|svg|webp`, до 200 КБ.
В `businesses.csv` менять только `logo_file` и `notes`; CRLF как сейчас
(Python: `newline=''`).

## Чего не делать

- Не брать иконку сайта 16–72 px, фото вывески, логотип из каталогов и
  Google Maps; не рисовать и не генерировать.
- Не трогать остальные столбцы, код сайта, другие города.

## Готово, когда

- **PR открыт**, заголовок `Kosice: logos`.
- `npm run check-city -- kosice` → `READY` («Logos too small» нет),
  вывод целиком в PR. Доля мест с настоящим логотипом (столбец `value`)
  — цель 80 %; меньше — только если у каждого остального места
  `logo: none (где смотрели)` (с 2026-09-28 честная пометка
  засчитывается, `quality.md`, правило 9).
- Все новые логотипы просмотрены на белом фоне в размере ~64 px.
- Самопроверка `quality.md` (§2) в PR.

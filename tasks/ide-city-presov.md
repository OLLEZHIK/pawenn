# Задача: город Prešov — третий словацкий город, партиями

**Исполнитель:** Antigravity IDE
**Роль:** Data agent.
**Тип:** новый город, куски по 10 мест с воротами, партия (PR) — 1–3 куска.
**Ветка PR:** `city/presov` (ветка города; в `main` город уводит
проверяющий одним PR, когда готовы все партии).
**Зависимости:** `tasks/ide-kosice-logos.md` — сначала она (маленькая).

Решение владельца (2026-09-28): следующие города — Prešov (Словакия) и
Kraków (Польша, задача Claude Code CLI (Mac)). Братислава — образец
(`docs/growth-strategy.md` §0): делать ровно по шаблону, не больше и не
меньше. Словацкий язык уже на сайте.

**Новое с 2026-09-28 (владелец) — прочитать до начала:**
`docs/playbooks/quality.md`, правила 8 и 9, и `docs/playbooks/add-city.md`,
разделы «Партии» и 1.4. Коротко: одна сессия — одна партия; к каждому
значению с сайта — цитата со страницы в `evidence-<NN>-<категория>.csv`;
не открылось — `none (...)`, это засчитывается. **С 2026-09-29:** правило
10 — кусками по 10 с `npm run gate` после каждого.

### Партия 0

2. `data/cities/presov/city.json` — `locale` `sk`, `locales` `["sk"]`,

4. `data/cities/presov/candidates.csv` — все найденные работающие места
   шести категорий: название, ссылка Maps и число оценок **копией** с

   каталога на категорию (только как список названий). Закрытые места
   не включать.
5. PR в `city/presov`: сколько кандидатов по категориям, какие запросы и
   каталоги, что с районами.

### Партии 1…n

**Кусками по 10 с воротами** (`quality.md`, правило 10): 10 мест в файле
куска `businesses-<NN>-<категория>.csv` (+ `evidence-<NN>-<категория>.csv`)
→ `cd website && npm run gate -- presov` → `GATE FAIL` — исправить по
списку, заново открыв источник, и снова (3-й круг: несошедшееся — пусто
и `none (...)`); `GATE PASS` — закоммитить кусок вместе со штампом
`data/cities/presov/checks/<NN>-<категория>.json` → следующие 10. `NN` —
номер куска в городе по порядку.

Места из строки таблицы — по **`docs/playbooks/add-city.md`**, поля — по
**`docs/card-spec.md`**: файлы `businesses-<NN>-<категория>.csv` и
`evidence-<NN>-<категория>.csv`, цены — дописать в `prices.csv`,
логотипы — `website/public/logos/presov/` (до 200 КБ, не меньше
128 px). Строки прошлых партий не трогать. Сводки отзывов не делать —
это отдельная задача после того, как город в `main`.

## Уроки Кошице и Варшавы

- **Тексты — про каждое место, с его сайта.** Один абзац на категорию
  с подставленным названием не принимается (`check-city` ловит). Цитата
  с сайта для `description` — в `evidence`.
- **Часы — все дни, что указывает место.** Строка из одних выходных
  (`sa closed; su closed`) — не часы. Нет нигде — пусто и
  `hours: none (...)`.
- Ссылка Google Maps, `google_place_id`, координаты и оценка — **только
  копией** с карточки; нет карточки — пусто и `maps: none (...)`.
- Телефон и сайт — сверить с сайтом места (`verify-city`); придуманный
  номер или несуществующий домен — возврат PR.
- Каждый код `facts` — цитата со страницы, где это написано (не
  главная, если там этого нет); ничего нет — `facts: none (site
  checked: ...)`. `appointment_only` — только по прямым словам («len na
  objednávku»).
- Цены: размер/порода без веса — одна строка без веса (`card-spec.md`,
  «Цены»); у каждой цены — цитата строки прайса; «prices: none (...)» —
  своя заметка у каждого места, где смотрел.
- Клиника и её врач с отдельными карточками Google — одно место.
- После ревью — только новые коммиты, без force-push.

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается,
`check-city` пропускает. Если так у трети мест партии и больше — не
собирать дальше: открыть PR с тем, что есть, и описать проблему в
разделе `## Открытый вопрос`. Сдать меньше мест с объяснением —
нормально; возврат PR бывает за выдумку, не за честный пробел.

## Чего не делать

- Не выдумывать и не «оценивать» (quality.md, правила 1, 7).
- Не брать больше мест, чем в строке таблицы.
- Не копировать тексты с сайтов дословно (цитаты — только в `evidence`).
- Не трогать код сайта, файлы других городов и прошлых партий.

## Готово, когда (для каждой партии)

- **PR открыт в `city/presov`** (коммит — не сдача), заголовок
  `City data: Prešov — партия <N> (<категория>)`.
- У каждого куска партии — `GATE PASS` (штамп в `checks/`).
- `cd website && npm run check-city -- presov` → `READY` (с таблицей
  «Gates») и `npm run verify-city -- presov` → `VERIFIED` (с партии 1),
  вывод обоих целиком в PR.
- В PR — самопроверка `quality.md` (§2), таблица заполненности по
  полям, что не нашлось и почему, где инструмент не сработал.

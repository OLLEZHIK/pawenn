**Исполнитель:** Antigravity (ПК) — контейнер выбирает диспетчер (`AGENTS.md`, владелец 2026-10-02); ветки `pcN/…`, где N — его номер.
**Роль:** Data agent
**Тип:** добор данных по сайтам, PDF и соцсетям, куски по 10, партии по 1–3 куска.
**Ветка PR:** `main`.
**Зависимости:** нет.
**Срочность:** сегодня (2026-10-02) — ревизия трёх городов, `docs/mvp-alpha.md`.

**Сейчас (проверяющий, 2026-10-02):** начать с партии 1. Страницы цен услуги индексируются, только если у ≥ 3 мест есть цена, — каждая новая цена укрепляет их.

Цены — главный актив сайта (`docs/growth-strategy.md` §2). Сейчас с ценами Bratislava 46 из 85 мест (39 — `prices: none`), Košice 27 из 59 (32 — `prices: none`). Часть — честное «не публикует», но прайс часто лежит в PDF, на отдельной странице или в Facebook.

Перед работой — `docs/playbooks/quality.md`, `docs/card-spec.md` (раздел «Цены») и `docs/playbooks/add-city.md` и `docs/pc-agents/lessons.md`.

## Что сделать

Для каждого места с `prices: none (...)`: заново открыть сайт (меню «Cenník / Služby / Ceny»), PDF, Facebook, Instagram. Нашёл — строки в `data/cities/<город>/prices.csv` только для 6 услуг категории из стандарта, с `source_url`, `observed_at` и цитатой. Не нашёл — обновить пометку `prices: none (…)` с новой датой и тем, где смотрел. Порядок: сначала ветклиники и грумеры (по ним строятся страницы цен).
Кусками по 10, после каждого — ворота: `cd website && npm run gate -- <город>`;
`GATE FAIL` — исправить по списку, заново открыв источник; `GATE PASS` —
закоммитить кусок вместе со штампом `checks/…json`; потом следующие 10.

К каждому значению с сайта — цитата со страницы в `evidence-*.csv` (`add-city.md`, раздел 1.4); не нашёл — `<поле>: none (...)`.

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается,
`check-city` пропускает. Если так у трети мест партии и больше — не
собирать дальше: открыть PR с тем, что есть, и описать проблему в
разделе `## Открытый вопрос`. Сдать меньше мест с объяснением —
нормально; возврат PR бывает за выдумку, не за честный пробел.

## Чего не делать

- Цену «от» без источника, среднюю по рынку и цену с агрегатора не ставить — только со страницы самого места.
- Не выдумывать и не «оценивать» (`quality.md`, правила 1, 7).
- Не трогать файлы вне задачи (код сайта, другие города, чужие партии).

## Готово, когда (для каждой партии)

- **PR открыт** в `main`, заголовок `Bratislava/Košice: цены — партия N`; перед PR `git pull --no-rebase origin main`.
- У каждого куска — `GATE PASS` (штамп в `checks/`).
- `cd website && npm run check-city -- <город>` → `READY` и `npm run verify-city -- <город>` → `VERIFIED`, `npm run agent-check` и `npm run sanity` — без FAIL; вывод целиком в PR.
- В `check-city` строка «Prices» не хуже прежней, у каждого `none` — пометка с датой.
- Самопроверка `quality.md` (§2) в PR.

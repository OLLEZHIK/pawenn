# Задача: город Kraków — второй польский город по шаблону

**Исполнитель:** Antigravity (Mac)
**Роль:** Data agent.
**Тип:** новый город, объём большой (до 100 мест).
**Ветка:** `mac/city-krakow`
**Зависимости:** `tasks/mac-warszawa-descriptions.md` — сначала она
(там новые проверки `check-city`, и её урок нужен здесь). Начать от
`main` после её мерджа.

Решение владельца (2026-09-28): следующие города — Kraków (Польша) и
Prešov (Словакия, задача IDE). Братислава — образец
(`docs/growth-strategy.md` §0): делать ровно по шаблону, не больше и не
меньше. Польский язык уже на сайте (Варшава, PR #169).

## Уроки Варшавы и Кошице (прочитать до начала)

- **Тексты — про каждое место, с его сайта.** Один абзац на категорию
  с подставленным названием не принимается (`add-city.md` §3,
  `check-city` ловит). Все 85 описаний Варшавы пришлось переписывать.
- **Телефоны и сайты — с карточки и сайта места, не набирать.** В
  первой версии Варшавы номера и домены были придуманы; `verify-city`
  это ловит — запускать до PR.
- **Факты — каждый код со ссылкой на страницу, где это написано.**
  Набор `card_payment;pet_passport;pharmacy_on_site` у всех клиник по
  главной странице — возврат PR. Ничего нет — `facts: none (site
  checked: ...)`.
- **Цены: не придумывать вес.** Прайс по породам — одна строка без веса,
  `price_from`/`price_to` — самая низкая и самая высокая цена
  (`card-spec.md`, «Цены»). Страницу «cennik» искать на каждом сайте,
  заметка `prices: none (...)` — своя у каждого места.
- Часы — `closed`, не `off`; слаги — только `a-z`, `0-9` и одиночные
  дефисы (`check-city` ловит оба).
- Ссылка Google Maps, `google_place_id`, координаты и оценка — только
  копией с карточки.
- После ревью — только новые коммиты, без force-push.

## Что сделать

Всё — по **`docs/playbooks/add-city.md`** (город `Kraków`, slug
`krakow`, страна `PL`, язык `pl`), поля — по **`docs/card-spec.md`**,
качество — по **`docs/playbooks/quality.md`**.

1. `data/cities/krakow/city.json` — `locale` `pl`, `locales` `["pl"]`,
   `in_city`: `{"en": "in Kraków", "pl": "w Krakowie"}`, `timezone`
   `Europe/Warsaw`, `currency` `PLN`.
2. `data/cities/krakow/districts.geojson` — 18 dzielnic из
   OpenStreetMap скриптом `scripts/fetch-districts.ts` (как в Варшаве);
   `admin_level` проверить в OSM и написать в PR. `name` — как в
   обиходе («Stare Miasto», «Nowa Huta»), без «Dzielnica I». Падеж `in`
   («na Kazimierzu», «w Nowej Hucie») — только если уверен, иначе
   только `en`.
3. `data/cities/krakow/businesses.csv` — все 6 категорий, все поля
   карточки, включая `facts`. `*_local` — живой польский. У ветклиник —
   языки обслуживания (иностранные, не `pl`). Закрытые места не
   добавлять. Мест больше лимита — по каждой категории с наибольшим
   числом оценок в Google, пропорционально Братиславе (ветклиники ≈
   половина); правило и число кандидатов — в PR.
4. `data/cities/krakow/prices.csv` — только опубликованные прайсы, в злотых.
5. Логотипы — `website/public/logos/krakow/`, до 200 КБ.
6. **Сводки отзывов не делать** — после мерджа это отдельная задача
   Antigravity (Desktop).

Запросы — главные варианты из `docs/seo/keywords/pl.md` («weterynarz
kraków», «groomer kraków», «hotel dla psów kraków», «szkolenie psów
kraków», «sklep zoologiczny kraków», «petsitter kraków»); сверка
полноты — 1–2 каталога на категорию.

## Чего не делать

- Не выдумывать и не «оценивать» (quality.md, правила 1, 7).
- Не копировать тексты с сайтов дословно и не брать тексты Варшавы.
- Не переводить цены в евро.
- Не трогать код сайта и файлы других городов.

## Готово, когда

- **PR открыт** (коммит — не сдача), заголовок `City data: Kraków`.
- `cd website && npm run check-city -- krakow` → `READY` и
  `npm run verify-city -- krakow` → `VERIFIED`, вывод обоих целиком в PR.
- В PR — самопроверка `quality.md` (§2), таблица заполненности по
  полям, сколько мест по категориям, правило отбора, какие каталоги
  сверяли, что не нашлось и почему.

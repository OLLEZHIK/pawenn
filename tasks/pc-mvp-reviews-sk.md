**Роль:** Content agent
**Тип:** сводки отзывов (нужен вход в Google, `docs/pc-agents/browser-setup.md`), куски по 10, партии по 1–3 куска.

## Что сделать

Список мест без сводки — места с ≥ 10 оценок, у которых нет `data/cities/<город>/review-insights/<slug>.json`, получить скриптом: `cd website && npm run check-city -- <город>` (строка «What customers say» и список ниже). Порядок — по числу оценок, по убыванию. Для каждого — лента `feed` и сводка по `review-insights.md` (≥ 20 оценок и ≥ 5 отзывов с текстом за полгода — иначе сводку не писать, место — `—` с причиной в PR). Языки: `en` + `sk`.
Кусками по 10, после каждого — ворота: `cd website && npm run gate -- <город>`;
`GATE FAIL` — исправить по списку, заново открыв источник; `GATE PASS` —
закоммитить кусок вместе со штампом `checks/…json`; потом следующие 10.

К каждому значению с сайта — цитата со страницы в `evidence-*.csv` (`add-city.md`, раздел 1.4); не нашёл — `<поле>: none (...)`.

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes`
`<поле>: none (<где смотрел, что не открылось>)`. Это засчитывается,
`check-city` пропускает. Если так у трети мест партии и больше — не
собирать дальше: открыть PR с тем, что есть, и описать проблему в
разделе `## Открытый вопрос`. Сдать меньше мест с объяснением —
нормально; возврат PR бывает за выдумку, не за честный пробел.

## Чего не делать

- Не пересказывать отзывы от имени клиентов — это «наша сводка» (`review-insights.md`).
- Google Maps из облака не открывается, ленту берёт только контейнер с входом в Google.
- Не выдумывать и не «оценивать» (`quality.md`, правила 1, 7).
- Не трогать файлы вне задачи (код сайта, другие города, чужие партии).

## Готово, когда (для каждой партии)

- **PR открыт** в `main`, заголовок `Košice/Bratislava: сводки отзывов — партия N`; перед PR `git pull --no-rebase origin main`.
- У каждого куска — `GATE PASS` (штамп в `checks/`).
- `cd website && npm run check-city -- <город>` → `READY` и `npm run verify-city -- <город>` → `VERIFIED`, `npm run agent-check` и `npm run sanity` — без FAIL; вывод целиком в PR.
- `check-city` — строка «What customers say» растёт до числа мест с ≥ 10 оценок минус честные «меньше 5 отзывов».
- Самопроверка `quality.md` (§2) в PR.

# Задача: Prešov — партия 0, кандидаты и проход Maps

**Исполнитель:** Claude Code CLI (локальный)
**Роль:** Data agent.
**Тип:** новый город, партия 0 (без мест), один PR.
**Ветка:** `cli/presov-00-maps`
**Ветка PR:** `city/presov` (ветка города; в `main` город уводит
проверяющий одним PR, когда готовы все партии).
**Зависимости:** нет. Эта задача разблокирует `ide-city-presov.md` и
`antigravity-city-presov.md` — брать первой.

Решения владельца: следующие города — Prešov и Kraków (2026-09-28);
специализация (2026-09-29, `AGENTS.md`, «Специализация») — всё с
Google Maps делает CLI, места по сайтам — Antigravity. Здесь CLI
собирает список мест города и копирует карточку Maps каждого; тексты,
цены, факты, логотипы потом соберёт Antigravity, скопировав Maps-поля
из этого списка.

Перед работой — `docs/playbooks/quality.md`, `docs/playbooks/add-city.md`
(разделы «Партии» — «Партия 0», 1.1, 4, 4.1) и `docs/card-spec.md` §5
(формат часов).

## Подготовка

Браузер — Playwright MCP с выполненным входом в Google (отдельный
аккаунт, не основной). Открыть карточку любого ветеринара в Prešove:
внизу нет «ограниченного вида» («limited view»), видны часы и вкладка
отзывов. Урезанный вид — не начинать, написать об этом в PR
(`## Открытый вопрос`).

## Что сделать

1. Ветка города, если её нет:
   `git fetch origin && git push origin origin/main:refs/heads/city/presov`.
   Своя ветка `cli/presov-00-maps` — от `origin/city/presov`.
2. `data/cities/presov/city.json` — `locale` `sk`, `locales` `["sk"]`,
   `in_city`: `{"en": "in Prešov", "sk": "v Prešove"}`, `timezone`
   `Europe/Bratislava`, `currency` `EUR` (образец — `data/cities/kosice/city.json`).
3. `data/cities/presov/districts.geojson` — части города из OpenStreetMap
   скриптом `website/scripts/fetch-districts.ts` (как в Кошице). Какой
   `admin_level` взял — в PR. Границ в OSM нет — файл не делать и
   написать об этом в PR (не рисовать самому). Падеж `in` («v Solivare») —
   только если уверен, иначе только `en`.
4. `data/cities/presov/candidates.csv` — все работающие места шести
   категорий, формат прохода Maps (`add-city.md`, «Партия 0»):

   ```
   category,name,google_maps_url,google_rating,google_rating_count,address,phone,website,opening_hours,observed_at,notes
   ```

   Запросы — главные варианты из `docs/seo/keywords/sk.md` («veterinár
   prešov», «strihanie psov prešov», «hotel pre psov prešov», «výcvik
   psov prešov», «chovateľské potreby prešov», «venčenie psov prešov»);
   сверка полноты — 1–2 каталога на категорию (только как список
   названий, данные — с карточки). Закрытые места не включать. Всё —
   **копией с карточки**: ссылка из адресной строки открытой карточки,
   рейтинг и число оценок как на ней (меньше 5 — пусто и
   `rating: none (...)`), часы — в формате `card-spec.md` §5 (нет на
   карточке — пусто). Сортировка — по категории, внутри по числу
   оценок, больше — выше.

**Кусками по 10 строк с проверкой:** 10 строк → `cd website && npm run
check-city -- presov` (раздел «Candidates» — без строк) → следующие 10.

## Если инструмент не работает

Карточка не нашлась по названию, адресу, телефону и сайту (`add-city.md`,
раздел 4) — место всё равно в списке, ссылка пустая, в `notes`
`maps: none (<где искал>)`. Это засчитывается. Если Maps урезан или не
открывается у трети мест и больше — остановиться: открыть PR с тем, что
есть, и описать проблему в разделе `## Открытый вопрос`.

## Чего не делать

- Не составлять ссылки Maps руками и не брать их из каталогов:
  `check-city` сверяет номер карточки и place ID в одной ссылке.
- Не брать рейтинг, часы, адрес из каталогов — только карточка.
- Не собирать тексты, цены, факты, логотипы — это партии Antigravity.
- Не трогать другие города и код сайта.

## Готово, когда

- **PR открыт в `city/presov`** (коммит — не сдача), заголовок
  `City data: Prešov — партия 0 (кандидаты и Maps)`.
- `cd website && npm run check-city -- presov` → `READY`, раздел
  «Candidates» без строк; вывод целиком в PR.
- В PR: сколько мест по категориям, какие запросы и каталоги, что с
  районами (`admin_level`), у скольких мест `maps: none` / `rating: none`
  / нет часов на карточке.
- 5 случайных строк — рядом скриншот или текст карточки (для сверки
  проверяющим).
- Самопроверка `quality.md` (§2) в PR.

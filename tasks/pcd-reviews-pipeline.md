# Задача: сводки отзывов — скрипт сбора и два этапа (диспетчер, любой город)

**Исполнитель:** Claude Code CLI (ПК, диспетчер) — раздаёт контейнерам; сам скрипт пишет и проверяет контейнер с рабочим методом (agy1) на живой странице Google.
**Роль:** Data agent (инструмент) + Content agent (сводки).
**Тип:** инструмент + конвейер, куски по 10 мест.
**Ветка PR:** `main` (скрипт и поправки), данные — в ветку города; сырые файлы — только `reviews-raw/<город>`.
**Зависимости:** нет.
**Срочность:** после снятия паузы владельцем.

**Сейчас (проверяющий, 2026-10-03):** ждёт слова владельца о снятии паузы. Решение владельца («давай это внедрим») — п. 1–4 ниже.

Зачем: сводок мало (Варшава 146 из 175, Bratislava 71 из 93, Košice 38 из 76, Краков 20 из 200), потому что один агент и кликает в браузере, и пишет. Рабочий метод ленты был у одного контейнера и лежал в `/tmp`. Порядок и правила — `docs/playbooks/review-insights.md`, «Два этапа».

Перед работой — `docs/playbooks/review-insights.md`, `docs/pc-agents/lessons.md`.

## Что сделать

- Скрипт: вход — `<город> [slug …]` или очередь `reviews-queue --slugs`; выход — `raw-reviews/<slug>.json` по формату из шапки `check-raw-reviews.ts`; `complete: true` только если долистал до 24 месяцев или до конца; при отказе места (урезанный вид без входа) — не писать файл, строка в лог; повтор мест, где файл не прошёл `check-raw-reviews`.
- Сырые файлы с текстом **не коммитить в `main`** и не открывать PR с ними: только ветка `reviews-raw/<город>`.
- Писатель: `feed` берёт из сырого файла без текста; `ago` копией; темы `topics` по смыслу; карточки и FAQ — по плейбуку; места `skip` не трогает (в PR — список с причиной).

## Если инструмент не работает

Не открылся сайт или Google Maps, нет данных — поле пустое, в `notes` `<поле>: none (<где смотрел, что не открылось>)`. Если лента не открывается у трети мест партии и больше — остановиться и описать в PR `## Открытый вопрос`; сдать меньше мест с объяснением — нормально.

## Чего не делать

- Не выдумывать записи ленты и не писать сводку по памяти (`quality.md`, правила 1, 7).
- Не копировать отзывы даже кусками (`review-insights.md`, «Честность»); не публиковать имена авторов.
- Не гнать скрипт быстрее, чем с паузой между местами; не использовать основной аккаунт Google.

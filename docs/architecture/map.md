# Карта в списке мест

**Решение владельца (2026-09-30):** в списке мест переключатель
«Zoznam | Mapa». Главное — телефон: человек видит, что рядом, и звонит
или строит маршрут прямо с карты.

**Статус:** бета. Переключатель видят только браузеры, открывшие любую
страницу с `?beta=1` (выключить — `?beta=0`), пока владелец не одобрит
выкладку для всех. Как снять бету — последний раздел.

## Как устроено

- `components/ListingMap.tsx` — переключатель, карточка выбранного места
  внизу карты («Zavolať», «Trasa», «Detail»), текст о местах без
  координат. Список остаётся в HTML и при открытой карте (прячется
  классом `hidden`): поисковики и браузеры без JS видят список как
  раньше.
- `components/ListingMapInner.tsx` — сама карта на
  [Leaflet](https://leafletjs.com/) (npm `leaflet`). Загружается только
  по нажатию «Mapa» (`next/dynamic`, `ssr: false`) — страницы списка не
  тяжелеют.
- Точки — все места отфильтрованного списка с координатами, а не только
  первые 20 из свёрнутого списка. Фильтры (открыто сейчас, рейтинг,
  признаки) работают и для карты, потому что точки берутся из того же
  списка (`components/CategoryListing.tsx`, `mapPoints`).
- **Места без координат на карту не ставятся по догадке:** под картой —
  «Bez presnej polohy, len v zozname: N». Координаты — только из данных
  города (`docs/card-spec.md`).
- С `?near=` (кнопка «Veterinár teraz», «V mojej blízkosti») синяя
  точка — посетитель, в карточке — расстояние.
- Цвет булавок — цвет категории (`CATEGORY_THEME`).
- Пока карта открыта, плавающая кнопка «Veterinár teraz» скрыта
  (`html[data-map-open]` в `app/globals.css`): она закрывала бы карточку
  места.
- Нажатия «Zavolať» и «Trasa» в карточке считаются так же, как в списке
  (`/api/click`, `docs/analytics/clicks.md`).

## Подложка карты

OpenStreetMap (`tile.openstreetmap.org`) с подписью «© OpenStreetMap».
Бесплатно, без ключа. Правила OSM допускают умеренное использование
сайтом с подписью, но не большой трафик. **Когда карту открывают
тысячи раз в день** — перейти на провайдера подложки с бесплатным
тарифом и ключом (MapTiler, Stadia Maps и т.п.): меняется одна строка
`L.tileLayer(...)` в `ListingMapInner.tsx` и подпись. Выбор провайдера,
если он платный, — решение владельца.

## Проверка

Локальная сборка, Playwright, экран 390×844, Братислава, ветеринары:
- без беты переключателя нет, с `?beta=1` — есть;
- «Mapa» → 52 булавки из 54 мест, «Bez presnej polohy, len v zozname: 2»;
- нажатие на булавку → карточка «PetVet veterinárna klinika, ★ 4.6,
  Petržalka» с кнопками «Zavolať / Trasa / Detail»;
- плавающая кнопка «Veterinár teraz» при открытой карте скрыта.

## Снять бету (после одобрения владельца)

В `components/ListingMap.tsx` заменить `const beta = useBeta();` на
`const beta = true;` и убрать импорт `useBeta`. Этот файл — обновить
(«Статус»).

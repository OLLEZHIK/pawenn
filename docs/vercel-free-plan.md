# План: сайт на бесплатном Vercel (владелец, 2026-10-11)

Решение владельца: **этот месяц последний платный**, дальше только бесплатный тариф (Hobby). Файл — что считаем, что делаем, что нужно от владельца.

## Что ограничивает Hobby (проверять по актуальной странице лимитов Vercel)
- Fluid Active CPU ~4 ч/мес, вызовов функций ~1 млн/мес, трафик ~100 ГБ/мес, сборка: до 45 мин, 100 выкладок в сутки.
- **Только некоммерческое использование** (условия Vercel). Реклама, партнёрские ссылки, платные размещения — риск блокировки. Решение владельца: идём на бесплатный тариф, риск принят или нет — сказать явно.
- Один пользователь; приватный репозиторий организации не подключить (наш — личный, ок).
- В том же аккаунте лежат другие проекты (`fat_caunter`, `gold-spread-tracker`): счётчик общий. Перенести их или проверить, что они не едят CPU.

## Где у нас уходит CPU (гипотеза, подтвердить цифрами)
1. Боты и краулеры, заново собирающие кэш страниц после каждой выкладки (пачка раз в сутки уже есть).
2. Страницы с фильтрами (`near`, `sort`, `rating`, `open`, `all`) — рендерятся на каждый запрос.
3. `sitemap.xml`, `llms.txt`, `/api/*` (отзывы, клики, og).
4. Сборка: `db-setup` (миграция + seed в Neon) на каждую выкладку.
Страниц на сайте уже десятки тысяч (≈2 500 мест × языки + листинги), будет больше (Италия, Франция).

## План (по убыванию пользы)
1. **Cloudflare перед Vercel (он уже стоит, `cf-ipcountry` читается в `proxy.ts`).** Правило «Cache Everything» для HTML `/<lang>/…` без query-фильтров, Edge TTL 7–30 дней, ответы с `s-maxage`. Боты бьют в кэш Cloudflare, до Vercel доходят промахи. Это главная мера. *Настройка аккаунта Cloudflare — делает владелец (или даёт доступ), инструкция ниже.*
2. **Закрыть тяжёлое ботам** (robots.txt + правило Cloudflare WAF): URL с `?near=`, `?sort=` и т. п. — `Disallow`, ограничить частоту агрессивных ботов (AI-краулеры разрешены решением 2026-09-21; можно оставить, но с rate limit).
3. **Выкладка реже:** с раза в 20 часов — до раза в неделю (`MIN_HOURS` в `website/scripts/vercel-ignore-build.sh`), `[deploy]` только срочное. Каждая выкладка сбрасывает кэш.
4. **Кэш данных** `REVALIDATE_SECONDS` уже 7 дней; не уменьшать.
5. **Запасной план — перенос статики на Cloudflare Pages/Workers (бесплатно, без лимита трафика)**; Vercel оставить только для динамики. Большая работа, делать, только если 1–3 не хватит.

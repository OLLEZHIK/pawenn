# Инструкция: статьи «Poradňa / Poradnik / Guides»

**Решение владельца (2026-09-30):** у каждой страны свой раздел статей
под частые запросы владельцев животных. Пишется на языке страны;
английская версия — только где есть спрос иностранцев. Внутри статей —
ссылки на страницы каталога, со страниц каталога — ссылки на статьи.
Это главный источник нового трафика из Google и ИИ-ассистентов.

Перед работой — `docs/playbooks/quality.md`. Статья — это факты, а не
«текст ради текста»: одна выдуманная деталь в статье о законе вредит
всему сайту.

## Где живут

| Язык | Раздел | Пример |
|---|---|---|
| sk | `/sk/poradna/` | `/sk/poradna/cipovanie-psa/` |
| pl | `/pl/poradnik/` | `/pl/poradnik/czipowanie-psa/` |
| en | `/en/guides/` | `/en/guides/travel-eu-dog/` |

- Файл статьи: `website/content/guides/<язык>/<slug>.md`. Slug — на
  языке статьи, главный запрос темы (`cipovanie-psa`, не `chip-sk-1`).
- Раздел языка появляется сам, когда в нём есть хотя бы одна статья:
  страница раздела, ссылка в футере, статьи в sitemap.
- Две версии одной статьи на разных языках связывает поле `pair`
  (одинаковое значение) — между ними ставится hreflang.

## Файл статьи

```
---
title: Čipovanie psa: do kedy, kto ho robí a koľko stojí | Pawenn
description: До 160 знаков: о чём статья и какой ответ в ней есть.
h1: Čipovanie psa na Slovensku
updated: 2026-09-30
country: SK
categories: VET_CLINIC
pair: microchip-dog
sources:
  - https://svps.sk/zvierata/cipovanie-psov/ | ŠVPS SR: Čipovanie psov | 2026-09-30
---
Текст в Markdown: ## подзаголовки, списки, **главное жирным**.
```

- `title` — до 60 знаков, главный запрос в начале; `description` — до
  160.
- `categories` — к каким категориям статья относится: на их страницах
  (в стране статьи) появится блок «Užitočné vedieť» со ссылкой на неё.
- `sources` — **только официальные источники** (ведомство, закон,
  сайт города), с датой проверки. Каждый факт статьи должен быть в
  одном из них. Нет источника — факта в статье нет.

## Живые блоки из каталога

Отдельной строкой в тексте:

- `::price VET_CLINIC microchip` — цена услуги по каждому городу страны
  (медиана, диапазон, число мест) со ссылкой на страницу цен. Код
  услуги — из `prices.csv`.
- `::places VET_CLINIC` — ссылки на категорию в каждом городе страны с
  числом мест.

Цифры в блоках берутся из данных при сборке сайта — статья не
устаревает, когда меняются цены. Писать цены из каталога руками в
текст нельзя.

## Ссылки

- В каждой статье — хотя бы один блок каталога (`::price` или
  `::places`) и ссылки на 1–2 соседние статьи раздела.
- Ссылки на статьи — только на существующие (проверяет скрипт).

## Правила текста

1. **Каждое утверждение — из источника.** Сумма, срок, возраст, штраф —
   дословно как в источнике (своими словами, но без новых деталей).
   Вывод, которого нет в источнике («это единственная обязательная
   прививка»), не писать.
2. Где правило зависит от обстоятельств (интервал прививки зависит от
   вакцины) — так и написать и отправить к ветеринару, а не выбирать
   цифру.
3. Живой язык страны, коротко: абзацы по 2–3 предложения, подзаголовки
   — вопросами, которые ищут («Do kedy musí mať pes čip»).
4. Не медицинские советы, а правила и цены. Лечение, дозировки,
   диагнозы — не наша тема.
5. `updated` — дата последней проверки источников; раз в полгода
   источники перепроверяются.

## Проверка перед PR

`cd website && npm run check-guides` → `READY`. Скрипт проверяет: поля
на месте, длину title/description, что у каждого источника есть https и
дата, что блоки называют существующие категорию и услугу, что ссылки
на статьи ведут на существующие статьи.

В PR — таблица «утверждение → цитата из источника (3–10 слов) →
ссылка» для каждой суммы, срока и штрафа. Проверяющий сверяет цитаты с
источником.

## Порядок работы

1. Темы — по исследованию запросов страны (задача агенту: запросы,
   спрос, есть ли официальный источник).
2. Статьи партиями по 3–5, каждая партия — PR с таблицей цитат.
3. Через месяц — Search Console: какие темы дают показы и клики;
   расширять то, что работает (например, тема «налог на собаку» — по
   каждому городу).

# Конкуренты Pawenn (Братислава / Словакия)

> Дата проверки: 2026-09-27. Цифры (число карточек, цены) сняты с
> публичных страниц сайтов в этот день через поиск и загрузку страниц.
> Это обзор без регистрации на сайтах и без ручного разбора каждого
> экрана. Интерфейсы Zocdoc, Rover и Yelp разобраны отдельно, в
> `docs/research/interface-references.md`.

Для сравнения: на pawenn.com сейчас 6 категорий. Ветклиник 54, отелей
11, зоомагазинов 9, грумеров 10, дрессировщиков 7, пет-ситтеров 4.
Язык: английский + словацкий. Без бронирования, у каждой карточки есть
ссылка на источник.

## Коротко

Прямого аналога, который делает всё то же, что Pawenn, нет. Нигде нет
сразу всех четырёх признаков: несколько категорий в одном месте, только
Братислава, английский язык, источник и дата проверки у каждой
карточки. Конкуренты делятся на 5 групп:

1. **Каталоги услуг для собак** (ближе всего по смыслу): Pes v Bratislave,
   Modrý psík, Chovateľ a hospodár, Salonprepsy.sk.
2. **Узкие каталоги одной вертикали**: BestVet.sk (только ветеринары).
3. **Общие каталоги фирм и SEO-агрегаторы**: Azet.sk, Zoznam.sk,
   bratislava.place, slovenskobcan.com. Главный конкурент — Google Maps.
4. **Онлайн-запись**: Reservio, Bookio.
5. **Площадки пет-ситтеров**: Hlídačky.sk, Petme, PetBacker, Fermeria.sk.

## Чем Pawenn отличается и где отстаёт

**Отличия, которых нет ни у кого из перечисленных вместе:**
- английский язык как основной — ниша экспатов не занята;
- все категории по одному городу в одном месте, с фильтром по виду
  животного;
- источник и дата проверки у каждой карточки, платное размещение
  помечено;
- без рекламы и регистрации, звонок в одно касание.

**Где конкуренты сильнее:**
- **Охват грумеров:** Modrý psík — 26, Azet — около 20, у нас 10.
- **Отзывы и рейтинги:** есть в Google, на Azet, bratislava.place,
  slovenskobcan. У нас их нет (решение из `docs/concept.md`).
- **Цены:** у bratislava.place есть диапазоны. На pawenn.com цен пока
  нет, хотя по концепции это главное отличие.
- **Специализации ветеринаров:** у BestVet их 12, плюс фильтр по виду
  животного.
- **Пет-ситтинг:** у маркетплейсов сотни исполнителей и бронирование.

## Что из этого следует (решения на усмотрение владельца)

1. Сайты Modrý psík, Salonprepsy, Azet, Zoznam, Reservio, Bookio можно
   использовать как **список наводок** для сбора грумеров и отелей. Сами
   данные с них не копировать: каждый факт проверять по сайту или
   странице самого бизнеса, как требует `PRODUCT.md`.
2. Добавить к ветклиникам атрибуты «24/7 / неотложка» и
   «англоговорящий персонал» (последний только по заявлению клиники на её
   сайте). Второго нет ни у одного конкурента, и он прямо закрывает
   нишу экспатов.
3. Для SEO-запросов «best vet Bratislava» / «najlepší veterinár» учесть,
   что там уже стоят агрегаторы с рейтингами. Наш козырь — проверенные
   данные и цены, их стоит показывать на таких страницах.
4. Pet sitting держать минимальным разделом со ссылками на площадки,
   а не пытаться собрать ситтеров самим.
5. Раз в квартал проверять **pesvbratislave.sk**: он ближе всех по
   концепции и может вырасти.

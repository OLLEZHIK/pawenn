   статей; после первых статей — проверить в браузере хаб и ссылки из

## 4. Когда альфа готова

- `npm run check-city` по трём городам — `READY`, `verify-city` — `VERIFIED`.
- Логотипов ≥ 80 % у каждого города; сводки у всех мест с ≥ 10 оценок
  (кроме честных «меньше 5 отзывов с текстом»).
- В Варшаве ветклиник ≥ 70, есть статьи `pl`.
- Владелец прошёл по трём городам в браузере со списком из раздела 3.

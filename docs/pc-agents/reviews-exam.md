# Экзамен по отзывам Google для Antigravity

Решение владельца (2026-10-01): проверить, может ли Antigravity собирать
ленту отзывов (`feed` в `review-insights`, `docs/playbooks/review-insights.md`)
так же точно, как CLI. Пока экзамен не сдан, отзывы и сводки — только CLI
(`AGENTS.md`, «Специализация»).

## Чем отличается от экзамена по карте

- **Эталона в репозитории нет**: ни в одной сводке ещё нет ленты. Поэтому
  эталон один раз собирает CLI (Mac) — задача
  `tasks/cmac-reviews-exam-reference.md`, 7 мест: 5 небольших и 2 с сотнями
  оценок — длинная лента проверяет, видит ли агент весь список.
- **Отзывы меняются каждый день.** Экзамен — не позже чем через 3 дня
  после эталона. Скрипт выравнивает ленты: у более свежей сверху может
  быть до 3 новых отзывов, а «месяцы назад» — на 1 больше.
- **Главный риск — вход в Google.** Без входа Maps в ЕС показывает не все
  отзывы и может не дать сортировку «Najnovšie». Такая лента будет
  короче — скрипт это ловит («count off by N»).

## Что собирается

На каждое место — **все отзывы с текстом за последние 24 месяца**,
сверху самые новые, по каждому только:

- `ago` — дата, как её пишет Google, копией («pred 3 mesiacmi»);
- `months` — число из неё (дни и недели → 0, «mesiac» → 1, «rok» → 12);
- `stars` — 1–5.

Без имён, без текстов отзывов, без тем.

Файл — JSON-массив:

```json
[
  { "name": "Veteris s.r.o.", "observed_at": "2026-10-02", "logged_in": true,
    "sort": "Najnovšie",
    "feed": [ { "ago": "pred 2 týždňami", "months": 0, "stars": 5 } ] }
]
```

```
cd website && npx tsx scripts/reviews-exam.ts ../data/exams/presov-reviews-reference.json ../data/exams/<файл экзамена>
```

**PASS:** все места найдены; число отзывов отличается от эталона не
больше чем на 2 (после выравнивания); у каждого места 90 % записей и
больше совпадают по звёздам и по «месяцам» (±1).

## Результаты

| Дата | Агент | Неверных | Итог | PR |
|---|---|---|---|---|
| 2026-10-01 | Antigravity (Mac 2), без входа в Google | 0 неверных из 11 видимых, но ленты обрезаны (5 из 16 у LEO, 2 из 4 у Veteris) | FAIL (среда) | #240 |

**Урок #240.** Без входа в Google Maps в ЕС показывает ровно 5 отзывов
(«obmedzené zobrazenie»), дальше — окно входа. Всё, что агент видел,
записано верно, — значит, мешает среда, а не точность. «pred 2 rokmi» —
это 24 месяца, в период 24 месяца **не входит** (`months` < 24).

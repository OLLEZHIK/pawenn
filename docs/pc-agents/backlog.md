# Бэклог задач для агентов на ПК

Очередь работы для Antigravity (ПК N). Ведёт проверяющий (облачный
Claude Code). Готовая задача — файл `tasks/pc-*.md` (без номера ПК:
контейнер выбирает диспетчер); здесь — что идёт
следом, чтобы у каждого контейнера была работа на несколько дней.

Что можно давать Antigravity: всё, что место или ведомство пишет о себе
само — сайты, официальные документы, реестры. Нельзя: Google Maps (только
CLI) и вид сайта (только CLI) — `AGENTS.md`, «Специализация».

## Следом (файлы задач появятся, когда освободится агент)

По приоритету. Источник приоритета — `docs/growth-strategy.md` и
`docs/seo/keywords/sk.md`.

1. **Новые города — только от 500 тысяч жителей** (владелец, 2026-10-01):
   Wrocław, Łódź, Poznań (`pl` уже есть); потом Praha, Wien, Budapest
   (новый язык — решение владельца). Каждый — по сайтам после партии 0
   от CLI (Google Maps), как было в Прешове. Узкое место — CLI: партию 0
   делает только он.
2. **Цены там, где их мало.** Warszawa (после `pc2-warszawa-prices.md`),
   Kraków, Bratislava (46 из 85, 2026-10-01): перепроверить прайсы на
   сайтах, PDF и соцсетях.
   Страницы цен услуги индексируются только при ≥ 3 ценах
   (`growth-strategy.md` §5.1).
3. **Атрибуты для страниц «english-speaking», «home-visits», «open
   Sunday», «exotic animals»** (`growth-strategy.md` §5.1): сверить
   `languages_spoken`, `home_visits`, `specialties` по сайтам с цитатами —
   по городам, кусками по 10.
4. **Площадки для выгула собак** (výbehy pre psov) — по открытым данным
   городов (`growth-strategy.md` §5.4). Сначала исследование: у каких
   городов есть официальный список.
5. **Польша — справочные данные** по образцу налога на собаку: что
   устанавливает гмина (opłata od posiadania psów — проверить, где
   действует), чипирование по городам. Сначала исследование.
6. **Аудит свежести по кругу**: раз в месяц `verify-city` по каждому
   городу (как `pc-audit-cities.md`).

## Правила для бэклога

- Новая задача для ПК — только по шаблону `docs/playbooks/task-template.md`,
  с пилотом и разделом «Отчёт о возможностях», пока тип задачи в
  `capabilities.md` — ❔.
- Один файл задачи — один агент. Два агента на один город — только по
  разным файлам данных (`businesses-*`, `evidence-*` своих кусков).

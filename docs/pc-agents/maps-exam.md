## Как устроен

- **Эталон** — места, которые CLI уже собрал с карты
  (`data/cities/<город>/candidates.csv`). У CLI в Кракове сошлись 481
  ссылка из 481, поэтому его данные — мерка.
- **Точное название — не неоднозначность.** Если в выдаче есть карточка
  с точно таким названием — берётся она; `card: ambiguous` — только когда
  точных совпадений несколько (урок экзамена 2, PR #236).
- **Вслепую.** Агент получает только название, категорию и город — и
  собирает с Google Maps те же поля, не заглядывая в `candidates.csv`
  (ни в файл, ни через `git show`, ни в ветку `city/<город>`).
- **Сравнение — скриптом**, значение за значением:
  ```
  cd website && npx tsx scripts/maps-exam.ts <город> <файл экзамена>
  ```
  Его запускает проверяющий на ветке `city/<город>`, где лежит эталон.

| Поле | Совпадение |
|---|---|
| место (`!19s…` в ссылке) | то же место |
| координаты (`!3d…!4d…`) | не дальше 50 м |
| `google_rating` | точно |
| `google_rating_count` | ±2 или ±3 % (число растёт со временем) |
| `address` | те же слова (60 % и больше) |
| `phone` | последние 9 цифр |
| `website` | тот же домен |
| `opening_hours` | точно, в формате `candidates.csv` |

## Оценка

- **WRONG** — значение есть, но не совпадает. Это главное: выдуманное
  или чужое значение на сайте хуже пустого.
- **BLANK** — пусто там, где у эталона есть значение: честный пробел.
- **PASS:** WRONG не больше 2 % от данных значений и покрытие от 80 %.

- **PASS на двух экзаменах подряд** (разные категории, 10 мест каждый) —

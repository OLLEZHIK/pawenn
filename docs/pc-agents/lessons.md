# Уроки для агентов-сборщиков

**Каждый Antigravity читает этот файл перед каждой задачей и каждой
партией** — диспетчер вставляет это требование в каждое поручение. Здесь
только то, на чём агенты уже ошибались. Правила целиком —
`docs/playbooks/quality.md`; урок — короткое напоминание, где именно
ошибаются.

**Кто пишет.** Диспетчер — после каждой «Поправки» (`dispatcher.md`),
проверяющий — после ревью. Новый урок — в конец, номер не меняется
никогда (на него ссылаются поправки и `agent-check`). Урок, который
закреплён проверкой в скрипте, остаётся здесь с пометкой «ловит …».

**Формат:** `У-NN` — правило одной фразой; почему (PR, дата); как
проверяется.

## Уроки

**У-01. Скрипты проверки не трогать** (`website/scripts/**`, `*-exam.ts`).
Скрипт не пускает — исправить данные или написать вопрос в PR, а не
менять скрипт. PR #228: агент сам расширил `evidence.ts`. Ловит
`agent-check`.

**У-02. Цитата — копия со страницы, не пересказ.** Скопировать строку
целиком из текста страницы (на JS-сайте — из текста бандла), не своими
словами. PR #228 (Dúbrava). Ловит `gate` (цитата не найдена на странице).

**У-03. Место без сайта — только то, что уже в строке.** Категория,
название, адрес из `candidates.csv`; ни имён, ни услуг, ни улиц «по
памяти». PR #228 (имена врачей L&L), PR #199 (улицы у 9 из 11 мест).
Проверяет напарник.

**У-04. Коммит — не сдача.** Работа сдана, когда открыт PR с
«Самопроверкой». Ветка без PR через сутки — работа потеряна для
конвейера. Ветка `mac/warszawa-descriptions`, 2026-09-29.

**У-05. Задачу читать в свежем `main`.** В своей ветке файл задачи
устаревший: ревью и ответы пишутся в `main`. `git pull origin main` до
чтения. 2026-09-29.

**У-06. Нет данных — `—` и причина, остановиться можно.** Инструмент не
показывает (Maps без входа, сайт не открылся) — не догадываться, написать
`none (почему)`; у трети партии — остановиться и спросить в PR. PR #197.

**У-07. Без рекламных слов от себя.** «modern», «professional»,
«experienced», «nowoczesny», «doświadczony» — только если это слова
самого места с цитатой; иначе — что место делает («USG i RTG»). Ревью
Варшавы, 2026-09-29. Ловит `check-city` («Texts that say more…»).

**У-08. Отзывы: «pred 2 rokmi» / «2 lata temu» — не входит в 24 месяца.**
В ленту — только то, что Google показывает моложе двух лет. PR #240.

**У-09. Точное название — ещё не то место.** Совпало название — сверить
адрес и район; два кандидата — оставить пусто, а не выбрать. Экзамен
Maps, PR #234.

**У-10. Один кусок — 10 мест, следующий — после `GATE PASS`, кусок
коммитится со штампом `checks/`.** Данные без штампа `check-city` не
пропустит. Ловит `agent-check`. Город со старым единым `businesses.csv` (Bratislava, Košice, Warszawa) кусков и ворот не имеет: там проверка — `check-city` `READY` и `verify-city` `VERIFIED` в PR (проверяющий, 2026-10-02, PR #244).

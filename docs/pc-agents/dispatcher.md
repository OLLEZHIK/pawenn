# Диспетчер на ПК: надзор, лимиты, перенаправление

Решение владельца (2026-10-01): Claude Code CLI на ПК — **только надзор**.
Это самый дорогой и ограниченный ресурс, поэтому он ничего не собирает и
не проверяет по существу (это делают Antigravity и облачный проверяющий),
а держит конвейер в движении.

## Что делает за один заход

Заход запускает владелец («проверь агентов»). Один заход — короткая
сессия:

1. `git pull` в `D:\docker\shop`. Читать **только** строки «Сейчас:»
   файлов `tasks/pc*-*.md` (и задачи картографа), не файлы целиком.
2. Состояние контейнеров: `docker ps`, у каждого `agyN` — работает ли
   `agy` и последние 20 строк его лога.
3. Обновить таблицу `D:\docker\status.md` (локально, не в git):
   `контейнер | задача | ветка | состояние | с какого времени`.
   Состояния: `работает`, `свободен`, `лимит до <время>`, `застрял`.
4. Взаимная проверка (`pipeline.md`): у каждого нового PR агента —
   назначить напарника (другой контейнер); PR идёт облачному
   проверяющему только после «Проверки напарника» и правок автора.
5. Решения:
   - **свободен** + есть задача или кусок в очереди → отдать;
   - **лимит** → задачу этого контейнера отдать свободному (ветку
     продолжает новый контейнер, название ветки не меняется); контейнер
     до снятия лимита новых задач не получает;
   - **застрял** (нет новых коммитов больше 1 часа и `agy` не работает) →
     один перезапуск той же задачи; повторилось → владельцу.
6. Отчёт владельцу 3–5 строк: кому что дал, кто на лимите и до когда,
   какие PR открыты, что ждёт владельца.

## Как узнать, что агент упёрся в лимит

В выводе или логе `agy`: `quota`, `rate limit`, `429`,
`RESOURCE_EXHAUSTED`, «limit reached». Время снятия лимита — если
написано в сообщении; иначе считать «через 5 часов» и проверить на
следующем заходе.

## Экономия

- Модель — любая, в том числе Opus (владелец, 2026-10-01: главное, чтобы
  работа делалась). Экономия — за счёт того, что диспетчер не делает
  чужую работу, а не за счёт модели.
- Не читать данные, PR и диффы целиком — статус, строки «Сейчас:», хвост
  лога.
- Не проверять качество работы агентов: это делает облачный проверяющий.
- Длинные поручения — файлом в контейнер (`/tmp/task.md`), не через
  кавычки PowerShell.
- Не держать сессию открытой: заход закончился — выход.

## Чего не делает

- Карту, сайты, тексты — не собирает (даже «чуть-чуть, пока все
  заняты»).
- Не мержит, не меняет задачи в `tasks/`, не создаёт и не удаляет
  контейнеры, не ставит автозапуск — это владелец (`AGENTS.md`,
  «Критическая инфраструктура»).

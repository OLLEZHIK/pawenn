# Конвейер нового города: CLI на карте, Antigravity на сайтах — параллельно

Решение владельца (2026-10-01). Раньше: CLI проходит Google Maps по всему
городу (партия 0, PR), его мёржат, и только потом Antigravity начинают
сайты. Теперь — потоком: каждые 10 мест с карты сразу уходят Antigravity.

```
CLI (ПК):    [карта 1–10] [карта 11–20] [карта 21–30] ...
                  │            │             │
agy1:             └─[сайты 1–10]             │
agy2:                          └─[сайты 11–20]
agy3:                                        └─[сайты 21–30]
```

## Роли

- **Claude Code CLI (ПК)** — диспетчер **и** исполнитель прохода Maps
  (у него браузер с Playwright и входом в Google). Задачи прохода Maps —
  `cpc-*.md`, ветки `cpc/…`.
- **Antigravity (ПК N)** — сайты мест, как в `add-city.md`; столбцы Maps
  копирует из строк CLI.

## Порядок

1. Город — только из бэклога и только от 500 тысяч жителей
   (`AGENTS.md`, «Проект»). Файл задачи прохода Maps — `cpc-city-<slug>.md`.
2. CLI создаёт ветку `cpc/<slug>-00-maps` от `city/<slug>` (ветку города
   создаёт CLI от свежего `main`, если её нет) и собирает
   `candidates.csv` кусками по 10 строк.
3. **После каждого куска:** коммит, push ветки, и сразу — поручение
   свободному контейнеру:
   «база — `origin/cpc/<slug>-00-maps`; места — строки N…N+9
   `candidates.csv`; кусок `NN`; ветка `pcK/<slug>-NN-<категория>`; PR в
   `city/<slug>`».
   Ветка Antigravity растёт от ветки CLI («стопка», `AGENTS.md`, шаг 3),
   поэтому в его PR сначала видны и строки CLI; после мержа PR CLI дифф
   сжимается сам.
4. Пока Antigravity работает, CLI продолжает карту. Свободного
   контейнера нет — кусок ждёт в очереди; CLI не делает сайты сам.
5. Когда карта пройдена — CLI открывает PR `cpc/<slug>-00-maps` в
   `city/<slug>`. Проверяющий смотрит его первым, потом PR кусков по
   порядку.
6. Пилот: у нового города первый кусок каждого Antigravity, который ещё
   не работал с этим типом задач, ждёт ревью (`capabilities.md`).

## Ограничения

- Порядок мест — порядок, в котором их собрал CLI (сортировка по числу
  оценок — внутри куска, не по городу).
- **Сборки Vercel.** Каждый push ветки с `data/` запускает сборку
  предпросмотра, а у бесплатного тарифа дневной лимит. При конвейере
  push-ей много. Решение — настроить Vercel не собирать ветки `cpc/*`,
  `pc*/*`, `city/*` (настройки Vercel — критическая инфраструктура,
  решает владелец). До этого — не больше одного push на кусок.
- Мержит всё по-прежнему владелец.

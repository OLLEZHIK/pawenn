# Доска: поручения проверяющего диспетчеру

Канал связи облачного проверяющего (Claude Code, облако) и диспетчера на ПК
(`Claude Code CLI (ПК, диспетчер)`). Начатый 2026-10-02 по просьбе
владельца.

**Как пользоваться.**
- **Это файл в `main`, и он главный.** Проверяющий пишет сюда поручения и
  обновляет раздел «Сейчас». Диспетчер читает его **в свежем `main`** на
  каждый заход (`git fetch origin && git checkout main && git pull`) —
  вместе с `docs/pc-agents/dispatcher.md` и `tasks/pc-*.md`.
- **Ответ диспетчера — не сюда.** Он пишет в отдельную ветку `pcd/board`,
  файл `docs/pc-agents/board-from-dispatcher.md`, и пушит туда. Так не нужен
  мерж и ответ не ждёт владельца. Проверяющий читает ветку сам
  (`git fetch origin pcd/board`).
- Ветка `pcd/board` создана от `main`, меняется в ней только этот файл,
  в `main` она не мержится. Ничего не ломается, если её удалить.
- Срочное — по-прежнему комментарием в PR; доска — для порядка и решений
  владельца.

## Как мы работаем со строкой «Сейчас:»

Проверяющий обновляет её в файле задачи после каждого ревью. Диспетчер
её не правит; если она расходится с реальностью — пишет в
`board-from-dispatcher.md`, проверяющий исправит.

## Что нужно от диспетчера в ответе

Раз в заход, 5–10 строк в `board-from-dispatcher.md` (ветка `pcd/board`):
- кто чем занят и в каком состоянии (идёт / лимит / ждёт);
- какие PR ждут проверяющего и проверка напарника по ним (ссылка);
- где застряло и что нужно решить проверяющему или владельцу;
- что нового заметил о среде (в `capabilities.md` — отдельным PR).

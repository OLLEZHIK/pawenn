# Карта способностей агентов на ПК

По этой карте диспетчер (Claude Code CLI на ПК) решает, какую задачу
какому агенту дать. Карта строится только на фактах из PR и ревью,
не на ожиданиях.

**Кто обновляет:**
- **Проверяющий** (облачный Claude Code, оркестратор) после каждого ревью
  задачи агента с ПК обновляет строку типа задачи тем же PR, что и
  ревью: оценку, ссылку на PR, что было не так.
- **Диспетчер** пишет наблюдения о среде: что сломалось при запуске,
  сколько шла задача, где агент застрял. Правка идёт через PR, как любая
  правка в `docs/`.

**Оценки:**
- ✅ **хорошо** — PR принят с первого-второго ревью, без выдумок;
- ⚠️ **с оговорками** — работает, но нужна узкая задача или особая проверка
  (что именно — в столбце «Замечания»);
- ❌ **плохо** — такие задачи агенту не давать;
- ❔ **не проверено** — давать только как пилот на 10 единиц с ревью.

**Правила для диспетчера:**
1. ✅ — давать как обычную задачу, конвейером.
2. ⚠️ — давать только с оговоркой из «Замечаний», прямо в тексте поручения.
3. ❔ — только пилот (одна партия, ждать ревью), и только одному агенту
   за раз.
4. ❌ — не давать; если такая задача в очереди ПК — сообщить владельцу,
   что её нужно отдать CLI или другому агенту.
5. Ограничения из `AGENTS.md` главнее карты: Google Maps и отзывы — CLI и контейнеры с входом в Google,
   фронтенд — только CLI, критическая инфраструктура — только владелец.

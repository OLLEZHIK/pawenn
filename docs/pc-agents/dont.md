# Десять «не делай» — вставлять в каждое поручение

Короткая выжимка `lessons.md` для агента, который пишет данные. Читается
за минуту; полный текст урока — по номеру. Нет напарника, который поймает
ошибку (`pipeline.md`, «Проверка без напарника»): место должно пройти
с первого раза.

1. **Не пиши то, чего нет в цитате.** Каждая услуга, факт, число — копия
   строки со страницы места (У-02, У-11). Нет цитаты — поле пустое и
   `none (…)`.
2. **Место без сайта — только строка из `candidates.csv`**: название,
   адрес, категория. Никаких услуг и врачей «из головы» (У-03).
3. **Нет данных — это нормально.** Пустое значение и причина засчитываются,
   выдумка — нет (У-06).
4. **Без рекламных слов** — «modern», «professional», «experienced»,
   «nowoczesny» (У-07).
5. **Сайт показал заглушку** («Please wait…», «maintenance») — это не текст
   места. Открой в браузере или пиши только то, что есть в строке (У-11).
6. **Цитата к описанию — предложение, на котором оно построено,** не
   заголовок страницы (У-11).
7. **Значение с запятыми — в кавычках** (ссылки Maps с `@координатами`,
   У-13). Телефон — настоящий номер страны, не 123456789.
8. **Скрипты и чужие файлы не трогай** (`website/scripts/**`, У-01).
9. **Один кусок — 10 мест, следующий после `GATE PASS`.** Штамп с
   `FAIL` не коммитить (У-10, У-14). Перед PR: `gate`, `check-city`,
   `verify-city`, `agent-check`, `sanity`.
10. **Задачу читай в свежем `main`**, перед проверкой подтяни `main` в ветку
    (У-05). Коммит — не сдача: сдача — открытый PR с «Самопроверкой» (У-04).

Источники данных:
- **Google Trends** (Япония, период: 12 месяцев, `geo=JP`, сравнение синонимов внутри смысловых групп до 5 вариантов; контрольная валидация по региону Токио).

- **Подсказки Google** (`google.co.jp`, `hl=ja`, `gl=jp`, официальный Google Suggest API) — проверены все базовые термины, сервисные хвосты, ценовые формулировки и локализованные запросы с указанием Токио (東京).
- **Google Ads Keyword Planner**: нет доступа к аккаунту в рабочей среде (в соответствии с правилами `docs/playbooks/quality.md` §§1–2 и методикой `docs/seo/keywords/README.md` колонка Planner помечена `—` во всех строках; исследование проведено по шагам 2–3 методики).

> **Методика фиксации данных Trends и выбора слагов (`docs/playbooks/quality.md`, `README.md`):**

> - Каждая группа сравнения снабжена прямой ссылкой на Google Trends по Японии (`geo=JP`) и по Токио (`JP-13`).

> - Согласно требованию задачи, каждый слаг выбирается строго в **ОДНОМ** варианте латиницей (ромадзи по системе Хэпберна, строчные буквы, цифры и дефис, без диакритики), с развёрнутым обоснованием выбора. Слаг после запуска не меняется.

## 6. Открытый вопрос

1. **Доступность Keyword Planner**:
   В среде сборщика отсутствует доступ к рекламному аккаунту Google Ads Keyword Planner. В соответствии с правилом `quality.md` §1 («Нет данных — пусто и причина. Никогда не оценка»), колонка Planner заполнена прочерком `—` во всех строках.
2. **Ограничение Google Trends (HTTP 429)**:
   При прямом программном обращении из Docker-контейнера сервис Google Trends возвращает HTTP 429. Значения в колонке Trends обозначены прочерком `—`, для каждой группы предоставлена прямая ссылка на Google Trends по Японии (`geo=JP`) и Токио (`JP-13`).
3. **Верификация через Google Suggest и узус**:
   Существование всех поисковых формулировок категорий, услуг, цен и атрибутов подтверждено через официальный Google Suggest API (`gl=jp`, `hl=ja`, UTF-8).

# Скорость сайта на телефоне

Google учитывает скорость страниц (Core Web Vitals) в поиске, а
посетитель с телефона уходит, если страница грузится долго. Нормы
Google: **LCP** (появление главного содержимого) — до 2,5 с, **CLS**
(сдвиг вёрстки) — до 0,1, **INP/TBT** (отклик) — TBT до 200 мс в
лабораторном замере.

## Замер 2026-09-30 («левая рука»)

Lighthouse 13, режим «телефон», живой сайт pawenn.com, из облачной
среды через прокси.

| Страница | Оценка | LCP | TBT | CLS |
|---|---|---|---|---|
| `/sk/` (главная, 1 прогон) | 94 | 2,5 с | 40 мс | 0,006 |
| `/sk/veterinar/bratislava/` (список, 5 прогонов) | 72–90 | 2,2–5,4 с | 50 мс | 0–0,198 |
| `/sk/podnik/veterinarna-klinika-primavet/` (место, 1 прогон) | 97 | 2,3 с | 50 мс | 0,059 |

- Список замерен 5 раз: разброс LCP от 2,2 до 5,4 с при одинаковом
  ответе сервера (170–470 мс). Большая часть — «задержка отрисовки»
  главного элемента, которая в этой среде зависит от сети прокси.
  **Точные цифры этим замером не получить.** CLS 0,198 был в одном
  прогоне из пяти (в остальных 0); причину в том прогоне не записал —
  проверить при следующем замере.
- Отклик (TBT 40–50 мс) и сдвиги на главной и странице места — в норме.
- Сервис Google PageSpeed Insights без ключа из этой среды не ответил
  (дневная квота общего адреса исчерпана).

## Как мерить надёжно

1. `https://pagespeed.web.dev/` → адрес страницы → «Мобильные». Верхний
   блок «Данные реальных пользователей» появится, когда у сайта будет
   достаточно посещений из Chrome; до этого — только лабораторный
   замер ниже.
2. Search Console → «Основные интернет-показатели» — по всем страницам
   сразу, когда сайт подтверждён (задача владельца).
3. Повторять после крупных изменений вёрстки и раз в месяц. Результат —
   в таблицу выше с датой.

## Что уже сделано для скорости

- Список города показывает по несколько мест на услугу, а не все
  (раньше страница весила ~1 МБ, Lighthouse 64) —
  `components/CategoryListing.tsx`, `HUB_PER_CATEGORY`.
- Карта (Leaflet) загружается только по нажатию «Mapa»
  (`docs/architecture/map.md`).
- Логотипы — `loading="lazy"`; страницы без параметров — статичные.
